# 欠款金额校验功能 - 快速测试指南

## 🎯 功能概述

在供应商详情页添加欠款时，如果上传了Excel产品明细文件，系统会自动校验：

- **欠款金额** 必须等于 **Excel中所有产品的金额总和**
- 如果不一致，将无法添加成功并显示错误提示

## 🔍 验证金额计算

### 如何确认Excel总金额

在Excel文件中，可以在空白单元格输入公式来验证：

```excel
=SUM(F2:F10)
```

其中 F列 是"金额"列，F2:F10 是数据范围。

### 示例验证

| 产品名称 | 金额                   |
| -------- | ---------------------- |
| 产品A    | 1005                   |
| 产品B    | 1000                   |
| **总计** | **=SUM(F2:F3)** → 2005 |

确保总计金额与填写的欠款金额一致。

## 🐛 常见问题

### Q1: 为什么金额明明一样，却提示不一致？

**A:** 可能是Excel中的"金额"列包含了隐藏的小数位。

**解决方案：**

- 在Excel中选中金额列
- 设置单元格格式为"数值"，保留2位小数
- 或者使用公式 `=ROUND(数量*单价, 2)`

---

### Q2: 如果Excel中有多个工作表怎么办？

**A:** 系统只读取**第一个工作表**的数据。

**建议：**

- 确保产品明细在第一个工作表
- 或者删除其他工作表，只保留数据工作表

---

### Q3: Excel中的"金额"列可以不填吗？

**A:** 不可以。"金额"列是必填字段，用于计算总金额。

**建议：**

- 在Excel中使用公式：`=数量*单价`
- 确保每行的金额都准确填写

---

### Q4: 能否调整误差容忍度？

**A:** 可以。在代码中修改 `tolerance` 变量：

```typescript
// 文件：/src/views/supplier/detail.vue
// 第213行

const tolerance = 0.01; // 当前：0.01元（1分）
```

**建议值：**

- `0` - 完全一致（可能因浮点数精度问题导致误判）
- `0.01` - 容忍1分（推荐）✅
- `0.1` - 容忍1角（较宽松）

## 🎓 技术说明

### 验证算法

```typescript
// 1. 解析Excel，提取所有产品数据
excelItems = await parseExcelFile(file);

// 2. 计算Excel总金额
excelTotalAmount = excelItems.reduce((sum, item) => sum + item.amount, 0);

// 3. 获取用户填写的欠款金额
debtAmount = addDebtForm.amount;

// 4. 计算差额的绝对值
difference = Math.abs(excelTotalAmount - debtAmount);

// 5. 判断是否在容忍范围内
if (difference > 0.01) {
  显示错误提示();
  return; // 阻止添加
}

// 6. 继续添加欠款
addSupplierDebt(...);
```
