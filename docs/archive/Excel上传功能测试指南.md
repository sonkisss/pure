# Excel上传功能测试指南

## 🎯 新增功能

### 1. **Excel模版下载**

- 在新增询价单弹窗中，Excel上传区域下方新增"下载Excel模版"按钮
- 点击按钮会下载包含示例数据的标准Excel模版

### 2. **字段验证规则**

- **严格字段验证**：Excel文件必须包含所有要求的字段
- **字段映射**：支持中英文字段名称
- **数据完整性验证**：产品名称为必填项

### 3. **错误提示优化**

- **详细错误信息**：明确指出缺少的字段
- **分层错误显示**：先显示失败提示，再显示具体错误
- **持久化提示**：错误信息不会自动消失，需用户手动关闭

## 📋 字段验证规则

### ✅ 必需字段

| 字段名   | 中文列名  | 英文列名支持                       | 验证规则            |
| -------- | --------- | ---------------------------------- | ------------------- |
| 产品名称 | 产品名称  | name, productName                  | 必填，不能为空      |
| 规格型号 | 规格型号  | specification, model, productModel | 可选                |
| 单位     | 单位      | unit                               | 可选，默认"个"      |
| 数量     | 数量      | quantity                           | 可选，默认1         |
| 价格     | 价格/单价 | price, unitPrice                   | 可选，默认0         |
| 金额     | 金额      | amount                             | 可选，默认数量×单价 |
| 供应商   | 供应商    | supplier                           | 可选                |
| 含税类型 | 含税类型  | taxType, 含税                      | 可选，默认"含税"    |
| 备注     | 备注      | remark, 备注说明                   | 可选                |

### ❌ 上传失败场景

1. **缺少必需字段**：Excel文件不包含任一必需字段
2. **产品名称为空**：某行的产品名称字段为空
3. **文件格式错误**：非Excel文件或文件损坏
4. **文件为空**：Excel文件没有数据行

## 🧪 测试步骤

### 1. **模版下载测试**

1. 访问 http://localhost:8848/
2. 登录系统 (admin/123)
3. 进入询价列表页面
4. 点击"新增询价"按钮
5. 在Excel上传区域点击"下载Excel模版"
6. **验证**：浏览器应下载"询价导入模版.xlsx"文件

### 2. **成功上传测试**

1. 打开下载的模版文件
2. 修改产品数据，保持字段结构不变
3. 在新增询价单弹窗中上传修改后的文件
4. **验证**：应显示成功消息，并跳转到详情页面

### 3. **字段验证失败测试**

#### 测试场景1：缺少字段

1. 创建Excel文件，只包含"产品名称"字段
2. 上传该文件
3. **验证**：应显示错误消息，指出缺少的字段

#### 测试场景2：产品名称为空

1. 使用标准模版，删除其中一行的产品名称
2. 上传该文件
3. **验证**：应显示错误消息，指出具体行号的问题

#### 测试场景3：完全错误的字段

1. 创建Excel文件，使用完全不相关的字段名
2. 上传该文件
3. **验证**：应显示错误消息，要求下载标准模版

### 4. **错误提示验证**

1. 触发任何上传失败场景
2. **验证**：
   - 应先显示红色错误提示"Excel文件上传失败"
   - 100ms后显示黄色警告提示，包含具体错误信息
   - 提示信息不会自动消失
   - 可以手动关闭提示

## 🔍 错误信息示例

```
Excel文件字段不符合模版要求，缺少字段：规格型号、单位。请下载标准模版并按照格式填写。
```

### 数据完整性验证失败

```
第 3, 5 行的产品名称为空，请检查数据完整性
```

### 文件为空

```
Excel文件为空
```

### 解析失败

```
Excel文件解析失败：[具体错误信息]
```

## 💡 使用建议

1. **先下载模版**：用户应首先下载标准模版
2. **保持字段结构**：不要删除或重命名模版中的列
3. **填写必填项**：确保每行都有产品名称
4. **检查格式**：确保文件格式正确，数据完整

## 🎨 界面优化

- **模版下载按钮**：小尺寸链接样式，配有下载图标
- **分隔线**：模版下载按钮与上传提示用虚线分隔
- **错误提示样式**：错误信息层级更高，不会被其他元素遮挡
- **响应式设计**：适配不同屏幕尺寸

现在用户可以享受更智能、更友好的Excel上传体验！
