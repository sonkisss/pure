# 欠款添加时间功能说明

## 📅 功能概述

为供应商欠款明细功能添加了"添加时间"字段，允许用户在添加欠款时自定义欠款的添加时间，并在欠款明细列表中显示"添加时间"而非"创建时间"。

---

## ✨ 功能详情

### 1️⃣ 添加欠款对话框新增字段

**新增字段**：

- **字段名称**：添加时间
- **字段类型**：日期时间选择器
- **是否必填**：是
- **默认值**：当前系统时间
- **格式**：`YYYY-MM-DD HH:mm:ss`

**表单位置**：

```
添加欠款对话框
├── 欠款金额
├── 欠款描述
├── 添加时间 ⭐ 新增
├── Excel文件
└── 图片凭证
```

**界面展示**：

```vue
<el-form-item label="添加时间" prop="addTime">
  <el-date-picker
    v-model="addDebtForm.addTime"
    type="datetime"
    placeholder="请选择添加时间"
    format="YYYY-MM-DD HH:mm:ss"
    value-format="YYYY-MM-DD HH:mm:ss"
    style="width: 100%"
  />
</el-form-item>
```

---

### 2️⃣ 欠款明细列表列名修改

**修改前**：

```
欠款金额 | 欠款描述 | Excel | 图片 | 创建时间 | 操作
```

**修改后**：

```
欠款金额 | 欠款描述 | Excel | 图片 | 添加时间 | 操作
```

**说明**：

- 将"创建时间"列名改为"添加时间"
- 显示内容不变，仍然使用`row.createTime`
- 但语义上更准确，表示用户选择的添加时间

### 2. API接口更新

**API类型定义**（`src/api/supplier.ts`）：

```typescript
/** 添加欠款 */
export const addSupplierDebt = (
  supplierId: number,
  data: {
    amount: number;
    description: string;
    addTime: string; // ⭐ 新增：添加时间
    imageBase64?: string; // 图片Base64字符串
  }
) => {
  return http.request<OperationResult>(
    "post",
    `/supplier/${supplierId}/debt/add`,
    { data }
  );
};
```

**调用示例**：

```typescript
const res = await addSupplierDebt(supplierId, {
  amount: addDebtForm.amount,
  description: addDebtForm.description,
  addTime: addDebtForm.addTime, // ⭐ 传递添加时间
  imageBase64: imageBase64 || undefined
});
```

## 🎯 使用场景

### 场景1：当天欠款录入

用户在当天录入欠款信息，默认使用当前时间即可。

**操作步骤**：

1. 点击"添加欠款"按钮
2. 填写欠款金额和描述
3. 添加时间默认为当前时间（可不修改）
4. 上传Excel或图片（可选）
5. 点击"确定"

---

### 场景2：历史欠款补录

用户需要补录几天前或几个月前的欠款信息。

**操作步骤**：

1. 点击"添加欠款"按钮
2. 填写欠款金额和描述
3. **修改添加时间**为历史日期时间 ⭐
4. 上传Excel或图片（可选）
5. 点击"确定"

**示例**：

```
欠款金额：50000
欠款描述：2024年10月原材料采购
添加时间：2024-10-15 14:30:00  ← 修改为历史时间
```

---

### 场景3：批量录入不同时间的欠款

财务人员整理历史账目，需要按实际发生时间录入多条欠款。

**操作步骤**：

1. 第一条：添加时间 = 2024-09-01
2. 第二条：添加时间 = 2024-09-15
3. 第三条：添加时间 = 2024-10-01
4. ...

**优势**：

- ✅ 时间准确，符合实际业务发生时间
- ✅ 便于后续按时间查询和统计
- ✅ 财务记录更加规范

## 📝 注意事项

### ⚠️ 开发注意

1. **时间格式统一**
   - 前端显示格式：`YYYY-MM-DD HH:mm:ss`
   - 提交格式：`YYYY-MM-DD HH:mm:ss`
   - 后端存储格式：建议ISO 8601

2. **时区问题**
   - 当前使用本地时区
   - 生产环境需考虑时区转换
   - 建议统一使用UTC时间存储

3. **时间验证**
   - 当前未限制未来时间
   - 业务需求可能需要限制选择范围
   - 可添加`disabledDate`配置

4. **Mock环境限制**
   - Mock中将`addTime`赋值给`createTime`
   - 实际生产环境应作为独立字段
   - 需要数据库表结构支持

### 💡 优化建议

1. **时间范围限制**（可选）

   ```vue
   <el-date-picker
     v-model="addDebtForm.addTime"
     type="datetime"
     :disabled-date="disabledDate"
   />
   ```

   ```typescript
   const disabledDate = (date: Date) => {
     // 不允许选择未来时间
     return date.getTime() > Date.now();
   };
   ```

2. **快捷时间选择**（可选）
   - 今天
   - 昨天
   - 一周前
   - 一个月前

3. **时间粒度**
   - 当前支持到秒级
   - 业务需求可能只需要到天级或小时级
