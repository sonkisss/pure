# 客户管理模块使用说明

## ✅ 已创建的文件

### 1. API 接口层

**文件路径：** `/src/api/customer.ts`

定义了客户管理相关的所有 API 接口：

- `getCustomerList()` - 获取客户列表（支持分页和搜索）
- `addCustomer()` - 添加新客户
- `deleteCustomer()` - 删除单个客户
- `batchDeleteCustomer()` - 批量删除客户
- `updateCustomer()` - 更新客户信息

### 2. Mock 数据层

**文件路径：** `/mock/customer.ts`

提供了开发环境的模拟数据：

- 自动生成 50 条测试客户数据
- 支持分页、搜索、增删改查等所有操作
- 使用 `@faker-js/faker` 生成真实感的测试数据

### 3. 路由配置

**文件路径：** `/src/router/modules/customer.ts`

配置了客户管理模块的路由：

- 路径：`/customer/index`
- 菜单名称：客户管理
- 图标：用户图标 (`ep:user`)

### 4. 页面组件

**文件路径：** `/src/views/customer/index.vue`

完整的客户管理页面，包含：

- 客户列表展示（表格）
- 关键词搜索功能
- 添加客户对话框
- 删除单个客户
- 批量删除客户
- 分页功能
- 数据加载状态

## 💡 开发技巧

### 如何添加编辑功能

1. 在 `/src/api/customer.ts` 中，`updateCustomer()` 接口已经定义好了

2. 在页面组件中添加编辑按钮和逻辑：

```vue
<!-- 在操作列添加编辑按钮 -->
<el-button link type="primary" :icon="Edit" @click="handleEdit(row)">
  编辑
</el-button>
```

```typescript
// 添加编辑相关代码
const currentEditId = ref<number | null>(null);

const handleEdit = (row: Customer) => {
  dialogTitle.value = "编辑客户";
  currentEditId.value = row.id;

  // 填充表单数据
  formData.name = row.name;
  formData.contact = row.contact;
  formData.phone = row.phone;
  formData.email = row.email || "";
  formData.address = row.address || "";

  dialogVisible.value = true;
};

// 修改提交逻辑
const handleSubmit = async () => {
  if (!formRef.value) return;

  await formRef.value.validate(async valid => {
    if (valid) {
      try {
        let res;
        if (currentEditId.value) {
          // 编辑
          res = await updateCustomer({
            id: currentEditId.value,
            ...formData,
            createTime: "" // 这个值会被忽略
          });
        } else {
          // 新增
          res = await addCustomer(formData);
        }

        if (res.success) {
          ElMessage.success(res.message);
          dialogVisible.value = false;
          loadCustomers();
        }
      } catch (error) {
        ElMessage.error("操作失败");
      }
    }
  });
};
```

### 如何对接真实后端

当您需要对接真实后端 API 时：

1. **配置后端地址**

编辑 `/src/utils/http/index.ts`，设置您的后端 API 地址

2. **禁用 Mock**

编辑 `/vite.config.ts`，注释或删除 Mock 相关配置

3. **调整接口路径**

根据后端实际接口路径，修改 `/src/api/customer.ts` 中的 URL

## ⚠️ 注意事项

1. **Mock 数据限制**
   - 当前使用 Mock 数据，刷新页面后添加的数据会重置
   - 数据仅存在于内存中，不会持久化

2. **后端对接**
   - 对接真实后端前，请确保后端接口符合前端定义的数据格式
   - 建议先在 Postman 等工具中测试后端接口

3. **权限控制**
   - 当前未添加权限控制，所有用户都可以操作
   - 如需权限控制，可参考 `/src/views/permission/` 下的示例

## 🆘 常见问题

**Q: 页面菜单中看不到客户管理？**

A: 请检查开发服务器是否正常运行，并刷新浏览器页面。路由会自动加载 `/src/router/modules/` 下的所有路由配置。

**Q: 点击添加客户后提示网络错误？**

A: 请确保 Mock 服务正常运行。检查浏览器控制台是否有错误信息。

**Q: 如何修改表格显示的字段？**

A: 编辑 `/src/views/customer/index.vue`，找到 `<el-table>` 组件，添加或删除 `<el-table-column>` 即可。

**Q: 如何自定义客户列表的初始数据？**

A: 编辑 `/mock/customer.ts`，修改 `generateCustomers()` 函数中的数据生成逻辑。
