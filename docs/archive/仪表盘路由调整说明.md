# 仪表盘路由调整说明

## ✅ 已完成的调整

仪表盘已从"首页"菜单下移动到与"客户管理"同级的位置。

---

## 📁 新的菜单结构

### 调整前

```
首页 (Home)
├── 首页 (Welcome)
└── 仪表盘 (Dashboard)  ← 在首页下

客户管理 (Customer)
└── 客户列表
```

### 调整后 ✅

```
首页 (Home)
└── 首页 (Welcome)

仪表盘 (Dashboard)  ← 独立菜单，与客户管理同级
└── 仪表盘

客户管理 (Customer)
└── 客户列表
```

## 🚀 访问路径

### 新的访问路径

| 方式         | 路径                                  |
| ------------ | ------------------------------------- |
| **菜单访问** | 左侧菜单 → 仪表盘                     |
| **直接访问** | http://localhost:8848/dashboard/index |

### 菜单显示顺序

1. **首页** (rank: 0)
2. **仪表盘** (rank: 1) ← 新位置
3. **客户管理** (rank: 2)

## 🔧 技术变更

### 创建的文件

✅ `/src/router/modules/dashboard.ts` - 独立的仪表盘路由配置

```typescript
const Layout = () => import("@/layout/index.vue");

export default {
  path: "/dashboard",
  name: "Dashboard",
  component: Layout,
  redirect: "/dashboard/index",
  meta: {
    icon: "ep:data-analysis",
    title: "仪表盘",
    rank: 1
  },
  children: [
    {
      path: "/dashboard/index",
      name: "DashboardIndex",
      component: () => import("@/views/dashboard/index.vue"),
      meta: {
        title: "仪表盘",
        showLink: true
      }
    }
  ]
} satisfies RouteConfigsTable;
```

### 修改的文件

✅ `/src/router/modules/home.ts` - 移除了仪表盘路由

**移除的代码：**

```typescript
// ❌ 已移除
{
  path: "/dashboard",
  name: "Dashboard",
  component: () => import("@/views/dashboard/index.vue"),
  meta: {
    title: "仪表盘",
    showLink: true
  }
}
```

## 🔄 自动路由加载

Vue Router 会自动加载 `/src/router/modules/` 目录下的所有路由配置文件。

**当前路由文件：**

```
/src/router/modules/
├── customer.ts      (客户管理)
├── dashboard.ts     (仪表盘) ← 新增
├── error.ts         (错误页面)
├── home.ts          (首页)
└── remaining.ts     (其他路由)
```
