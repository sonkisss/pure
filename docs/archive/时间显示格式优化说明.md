# 时间显示格式优化说明

## 📝 修改概述

优化供应商详情页中欠款明细和付款记录的时间显示格式，**只显示日期（YYYY-MM-DD）**，不显示具体的时分秒，使界面更简洁清爽。

---

## 🔄 修改内容

### 1. 新增日期格式化函数

```typescript
// 格式化日期（仅日期，不含时分秒）
const formatDate = (time: string) => {
  return dayjs(time).format("YYYY-MM-DD");
};
```

### 2. 修改欠款明细表格 - "添加时间"列

**修改前**：

## 💡 优化理由

### 1. **简化信息展示**

- 对于财务记录，通常只需要关注日期
- 具体到时分秒的信息在列表中价值不大
- 减少视觉干扰，提升阅读效率

### 2. **节省表格空间**

- 原格式：`2025-11-09 01:53:35`（19个字符）
- 新格式：`2025-11-09`（10个字符）
- 节省约50%的列宽空间

### 3. **保持数据一致性**

- 付款日期本身就是日期格式（YYYY-MM-DD）
- 现在所有时间列都统一为日期格式
- 视觉上更协调统一

### 4. **符合业务场景**

- 财务记录通常按天统计
- 欠款和付款一般不需要精确到秒
- 日期级别的精度已足够

## 🔍 技术细节

### 格式化函数对比

```typescript
// 原有函数（保留用于其他需要完整时间的场景）
const formatTime = (time: string) => {
  return dayjs(time).format("YYYY-MM-DD HH:mm:ss");
  // 输出: 2025-11-09 01:53:35
};

// 新增函数（用于表格显示）
const formatDate = (time: string) => {
  return dayjs(time).format("YYYY-MM-DD");
  // 输出: 2025-11-09
};
```

### 使用场景区分

| 场景         | 函数           | 格式                | 用途            |
| ------------ | -------------- | ------------------- | --------------- |
| 欠款明细列表 | `formatDate()` | YYYY-MM-DD          | ✅ 简化显示     |
| 付款记录列表 | `formatDate()` | YYYY-MM-DD          | ✅ 简化显示     |
| 付款日期列   | 无需格式化     | YYYY-MM-DD          | ✅ 本身就是日期 |
| 对话框详情   | `formatTime()` | YYYY-MM-DD HH:mm:ss | 如需精确时间    |
| 日志记录     | `formatTime()` | YYYY-MM-DD HH:mm:ss | 如需精确时间    |
