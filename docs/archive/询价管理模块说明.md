## 📊 数据结构

### 询价单（Inquiry）

```typescript
{
  id: number;                    // 询价单ID
  name: string;                  // 询价名称
  date: string;                  // 询价日期
  createTime: string;            // 创建时间
  itemCount: number;             // 产品明细数量
  matchedCount: number;          // 已匹配产品数量
  attachments: Attachment[];     // 附件列表
  items: InquiryItem[];         // 询价单明细（仅详情接口返回）
}
```

### 询价单明细（InquiryItem）

```typescript
{
  id: number;                           // 明细ID
  inquiryId: number;                    // 询价单ID
  productId: number | null;             // 关联的产品ID（匹配后）
  name: string;                         // 产品名称
  specification: string;                // 规格型号
  unit: string;                         // 单位
  price: number;                        // 价格
  supplier: string;                     // 供应商
  taxType: "普票" | "含税13%" | "";    // 含税类型
  remark: string;                       // 备注
  matchStatus: "matched" | "unmatched" | "multiple";  // 匹配状态
  matchedProducts?: Product[];          // 匹配到的多个产品（供选择）
}
```

### 附件（Attachment）

```typescript
{
  id: number; // 附件ID
  fileName: string; // 文件名
  fileUrl: string; // 文件URL（Base64）
  fileType: string; // 文件类型
  uploadTime: string; // 上传时间
}
```

## 🎨 功能演示

### 1. 新增询价单

1. 点击"新增询价"按钮
2. 填写询价名称（必填）
3. 选择询价日期（必填）
4. 点击"确定"提交

### 2. Excel导入询价单

1. 点击"Excel导入"按钮
2. 填写询价名称和日期
3. 上传Excel文件（字段与产品表一致）
4. 点击"上传并匹配"
5. 系统自动解析Excel并匹配产品
6. 查看匹配结果：
   - **已匹配**：绿色标签，自动匹配成功
   - **未匹配**：灰色标签，点击"手动匹配"按钮选择产品
   - **多个匹配**：橙色标签，点击"选择产品"按钮选择正确的产品
7. 确认后点击"确认保存"

### 3. 查看询价详情

1. 在列表中点击"查看详情"按钮
2. 进入详情页，查看：
   - 询价基本信息（名称、日期、匹配统计）
   - 附件列表
   - 产品明细列表

### 4. 附件管理

1. 在详情页点击"上传附件"按钮
2. 选择文件（支持图片、PDF、Word、Excel）
3. 点击"确定上传"
4. 附件上传后可查看或删除
5. 图片附件支持预览功能

### 5. 产品匹配处理

**对于"多个匹配"的产品：**

1. 点击"选择产品"按钮
2. 查看所有匹配的产品（产品名称和规格型号相同，但供应商可能不同）
3. 选择正确的产品
4. 点击"选择"按钮确认

**对于"未匹配"的产品：**

1. 点击"手动匹配"按钮
2. 从产品列表中选择合适的产品
3. 点击"选择"按钮确认
4. 产品信息会更新为选择的产品

## 🔍 产品智能匹配规则

系统会自动按以下规则匹配产品：

1. **完全匹配**：产品名称 + 规格型号 完全相同
2. **匹配结果**：
   - 匹配到 0 个产品 → 状态：**未匹配**
   - 匹配到 1 个产品 → 状态：**已匹配**
   - 匹配到多个产品 → 状态：**多个匹配**（需要手动选择）

### 示例

假设产品列表中有：

- 产品A：螺丝刀 / SD-001 / 供应商1
- 产品B：螺丝刀 / SD-001 / 供应商2
- 产品C：螺丝刀 / SD-002 / 供应商1

Excel导入数据：

- 螺丝刀 / SD-001 → **多个匹配**（匹配到产品A和产品B）
- 螺丝刀 / SD-002 → **已匹配**（匹配到产品C）
- 螺丝刀 / SD-003 → **未匹配**（没有匹配到任何产品）

## 💡 使用提示

1. **Excel文件格式**：确保Excel文件包含以下字段：
   - 产品名称
   - 规格型号
   - 单位
   - 价格
   - 供应商
   - 含税类型（可选：普票、含税13%）
   - 备注（可选）

2. **匹配优化**：
   - 产品名称和规格型号必须与产品库完全一致才能自动匹配
   - 建议先在产品管理模块中维护好产品库
   - 对于新产品，可以先添加到产品库再导入询价单

3. **附件管理**：
   - 支持上传图片、PDF、Word、Excel等格式
   - 图片附件可以直接预览
   - 其他格式附件会在新窗口打开

4. **数据安全**：
   - 删除询价单会同时删除所有明细和附件
   - 建议定期导出重要询价单数据

## 🛠️ 技术实现

### 核心功能

1. **产品智能匹配算法**（`mock/inquiry.ts`）

```typescript
const matchProducts = (item: any) => {
  const matched = mockProductsForMatching.filter(
    p => p.name === item.name && p.specification === item.specification
  );

  if (matched.length === 0) {
    return { matchStatus: "unmatched", productId: null, matchedProducts: [] };
  }

  if (matched.length === 1) {
    return {
      matchStatus: "matched",
      productId: matched[0].id,
      matchedProducts: []
    };
  }

  return { matchStatus: "multiple", productId: null, matchedProducts: matched };
};
```

2. **Excel解析**：使用 `xlsx` 库解析Excel文件
3. **附件存储**：Base64编码存储在Mock数据中
4. **图片预览**：使用 Element Plus 的 `el-image` 组件
