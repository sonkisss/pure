## 🔧 技术实现

### 新增 API 接口

**文件：** `/src/api/customer.ts`

```typescript
/** 获取客户统计信息 */
export type CustomerStatisticsResult = {
  success: boolean;
  data: {
    totalCustomers: number; // 客户总数
    debtCustomers: number; // 有欠款客户数
    totalDebt: number; // 总欠款
    zeroDebtCustomers: number; // 无欠款客户数
  };
};

export const getCustomerStatistics = () => {
  return http.request<CustomerStatisticsResult>("get", "/customer/statistics");
};
```

### Mock 数据接口

**文件：** `/mock/customer.ts`

```javascript
{
  url: "/customer/statistics",
  method: "get",
  response: () => {
    const totalCustomers = mockCustomers.length;
    const debtCustomers = mockCustomers.filter(item => item.debt > 0).length;
    const totalDebt = mockCustomers.reduce((sum, item) => sum + item.debt, 0);
    const zeroDebtCustomers = mockCustomers.filter(item => item.debt === 0).length;

    return {
      success: true,
      data: {
        totalCustomers,
        debtCustomers,
        totalDebt,
        zeroDebtCustomers
      }
    };
  }
}
```

## 📊 数据计算逻辑

### 统计范围

⚠️ **重要说明：**

- 统计的是**全部客户**的数据（不分页）
- 与客户列表页面的统计不同，仪表盘显示全局统计
- 数据通过独立的统计接口获取

### 计算公式

```javascript
客户总数 = 所有客户数量
有欠款客户 = 欠款 > 0 的客户数量
无欠款客户 = 欠款 = 0 的客户数量
总计欠款 = Σ(所有客户的欠款)
```

### 数据验证

```javascript
客户总数 = 有欠款客户 + 无欠款客户 ✓
```

## ⚠️ 注意事项

1. **Mock 数据环境**
   - 当前使用 Mock 数据
   - 统计的是内存中的 50 条测试数据
   - 刷新页面后数据会重置

2. **对接真实后端**
   - 后端需要提供 `/customer/statistics` 接口
   - 返回格式需要与类型定义一致
   - 建议添加缓存机制提高性能

3. **性能考虑**
   - 统计接口应该在数据库层面计算
   - 避免获取所有客户数据后前端计算
   - 可以考虑添加定时自动刷新
