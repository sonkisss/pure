## 📖 技术实现

### 1. API 接口层

**客户管理：**

```typescript
// src/api/customer.ts
export const updateCustomer = (data: Customer) => {
  return http.request<OperationResult>("put", "/customer/update", { data });
};
```

**供应商管理：**

```typescript
// src/api/supplier.ts
export const updateSupplier = (data: Supplier) => {
  return http.request<OperationResult>("put", "/supplier/update", { data });
};
```

### 2. Mock 数据层

**客户管理：**

```typescript
// mock/customer.ts
{
  url: "/customer/update",
  method: "put",
  response: ({ body }) => {
    const index = mockCustomers.findIndex(item => item.id === body.id);
    if (index !== -1) {
      mockCustomers[index] = { ...mockCustomers[index], ...body };
      return { success: true, message: "更新成功" };
    }
  }
}
```

**供应商管理：**

```typescript
// mock/supplier.ts
{
  url: "/supplier/update",
  method: "put",
  response: ({ body }) => {
    const index = mockSuppliers.findIndex(item => item.id === body.id);
    if (index !== -1) {
      mockSuppliers[index] = { ...mockSuppliers[index], ...body };
      return { success: true, message: "更新成功" };
    }
  }
}
```

### 3. 前端页面层

**统一的实现模式：**

```vue
<script setup>
// 1. 导入 API
import { updateCustomer/updateSupplier } from "@/api/...";

// 2. 对话框状态
const editDialogVisible = ref(false);
const currentItem = ref(null);
const editAmount = ref(0);

// 3. 双击处理
const handleDblClick = (row) => {
  currentItem.value = row;
  editAmount.value = row.debt/totalPayable;
  editDialogVisible.value = true;
};

// 4. 提交修改
const handleSubmit = async () => {
  const updated = { ...currentItem.value, debt/totalPayable: editAmount.value };
  await updateCustomer/updateSupplier(updated);
  loadData();
};
</script>

<template>
  <!-- 5. 双击事件 -->
  <span @dblclick="handleDblClick(row)" class="xxx-cell">
    ¥{{ row.debt / totalPayable.toFixed(2) }}
  </span>

  <!-- 6. 修改对话框 -->
  <el-dialog v-model="editDialogVisible">
    <!-- 表单内容 -->
  </el-dialog>
</template>

<style>
/* 7. 悬停样式 */
.xxx-cell {
  cursor: pointer;
  &:hover {
    background-color: #f0f9ff;
    transform: scale(1.05);
  }
}
</style>
```

## ⚠️ 注意事项

### 1. 数据覆盖

- 双击修改会**直接覆盖**原有金额
- 不是在原有基础上增减
- 修改前请确认当前金额

### 2. 与其他功能的关系

**客户管理：**

- **双击修改**：直接设置欠款总额
- **收款操作**：从欠款中减去收款金额
- 两种方式互补使用

**供应商管理：**

- **双击修改**：直接设置应付款总额
- **付款操作**（详情页）：减少欠款明细
- 两个维度独立管理

### 3. 权限控制

- 当前所有用户都可以修改
- 建议生产环境添加权限验证
- 可以记录修改日志（审计）

### 4. 数据验证

- 金额必须 ≥ 0
- 自动保留两位小数
- 输入非法值会提示错误
