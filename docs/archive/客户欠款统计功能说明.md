# 客户欠款统计功能说明

## ✅ 新增功能

在客户列表页面顶部添加了**欠款统计卡片**，实时显示客户欠款情况。

---

## 📊 统计内容

### 统计卡片显示三项数据：

| 统计项         | 说明                    | 数据来源               |
| -------------- | ----------------------- | ---------------------- |
| **客户总数**   | 当前页面显示的客户数量  | 实时统计               |
| **有欠款客户** | 欠款金额 > 0 的客户数量 | 实时统计，橙色显示     |
| **总计欠款**   | 所有客户的欠款总和      | 实时统计，红色粗体显示 |

## 💡 功能特性

### 1. **实时计算**

- 所有统计数据都是**实时计算**的
- 基于当前页面显示的客户数据
- 使用 Vue 的 `computed` 响应式计算

### 2. **动态更新**

统计数据会在以下操作后自动更新：

- ✅ 添加新客户
- ✅ 删除客户
- ✅ 收款操作（减少欠款）
- ✅ 搜索筛选
- ✅ 分页切换

### 3. **视觉设计**

- **客户总数**：普通黑色，大字号显示
- **有欠款客户**：橙色（`#f97316`），提示关注
- **总计欠款**：红色粗体（`#dc2626`），醒目强调

---

## 🔧 技术实现

### 计算属性

```typescript
// 计算总欠款
const totalDebt = computed(() => {
  return tableData.value.reduce((sum, customer) => sum + customer.debt, 0);
});

// 计算有欠款的客户数量
const debtCustomerCount = computed(() => {
  return tableData.value.filter(customer => customer.debt > 0).length;
});
```

### 模板代码

```vue
<el-card shadow="never" class="mb-4">
  <div class="statistics-container">
    <div class="stat-item">
      <div class="stat-label">客户总数</div>
      <div class="stat-value">{{ tableData.length }}</div>
    </div>
    <div class="stat-divider"></div>
    <div class="stat-item">
      <div class="stat-label">有欠款客户</div>
      <div class="stat-value text-orange-500">{{ debtCustomerCount }}</div>
    </div>
    <div class="stat-divider"></div>
    <div class="stat-item">
      <div class="stat-label">总计欠款</div>
      <div class="stat-value text-red-600 font-bold">
        ¥{{ totalDebt.toFixed(2) }}
      </div>
    </div>
  </div>
</el-card>
```

## 🎯 数据说明

### 统计范围

⚠️ **重要说明：**

- 统计的是**当前页面显示的客户数据**
- 如果使用了搜索，统计的是**搜索结果**
- 分页时，统计的是**当前页的数据**

### 准确性

✅ **数据准确性保证：**

- 使用 Vue 的响应式系统
- 所有统计都是基于最新的 `tableData`
- 每次数据变化都会自动重新计算
