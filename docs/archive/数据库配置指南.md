# 🗄️ PostgreSQL数据库配置指南

## 📋 概述

本指南将帮助您完成Vue 3 Admin项目与Sealos云平台PostgreSQL数据库的连接配置。

## 🔧 配置步骤

### 第一步：获取数据库连接信息

1. **登录Sealos控制台**
   - 访问：https://hzh.sealos.run
   - 进入数据库管理

2. **查找PostgreSQL实例**
   - 找到名称为 `vue3-admin-db` 的数据库实例
   - 点击"详情"或"连接信息"

3. **记录以下信息**：
   ```
   - 主机地址 (Host)
   - 端口号 (Port，通常是5432)
   - 数据库名称 (Database Name)
   - 用户名 (Username)
   - 密码 (Password)
   - SSL连接设置
   ```

### 第二步：更新云端数据库配置

1. **SSH连接到云端服务器**

   ```bash
   ssh hzh.sealos.run_ns-ci7ty6w8_vue3-admin-dev
   ```

2. **编辑配置文件**

   ```bash
   cd pure-admin-thin
   nano .env.production.local
   ```

3. **填入实际数据库信息**
   ```bash
   # 数据库配置
   DB_HOST=你的数据库主机地址
   DB_PORT=5432
   DB_NAME=vue3-admin-db
   DB_USER=postgres
   DB_PASSWORD=你的实际数据库密码
   DB_SSL=true
   DB_CONNECTION_TIMEOUT=30000
   ```

### 第三步：测试数据库连接

1. **等待依赖安装完成**

   ```bash
   # 查看安装进度
   npm list pg dotenv
   ```

2. **测试连接**

   ```bash
   # 方法1：使用测试脚本
   node test-db-connection.js

   # 方法2：在应用中测试
   # 访问 https://jstoxaqbmlet.sealoshzh.site
   # 进入数据库管理页面测试
   ```

### 第四步：创建数据库表结构（可选）

如果需要创建实际的数据表，可以使用以下SQL：

```sql
-- 创建用户表
CREATE TABLE IF NOT EXISTS users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    roles TEXT[] DEFAULT ARRAY['common'],
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 创建供应商表
CREATE TABLE IF NOT EXISTS suppliers (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    contact_person VARCHAR(100),
    phone VARCHAR(20),
    email VARCHAR(100),
    total_payable DECIMAL(15,2) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 创建产品表
CREATE TABLE IF NOT EXISTS products (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    specification VARCHAR(200),
    unit VARCHAR(20),
    purchase_price DECIMAL(10,2),
    supplier_id INTEGER REFERENCES suppliers(id),
    tax_type VARCHAR(50),
    remarks TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_suppliers_name ON suppliers(name);
CREATE INDEX IF NOT EXISTS idx_products_name ON products(name);
CREATE INDEX IF NOT EXISTS idx_products_supplier_id ON products(supplier_id);
```

## 🔍 故障排除

### 常见问题

1. **连接超时**

   ```
   解决方案：
   - 检查数据库主机地址是否正确
   - 确认防火墙设置
   - 增加连接超时时间
   ```

2. **SSL连接失败**

   ```
   解决方案：
   - 确认数据库是否支持SSL
   - 尝试禁用SSL连接（DB_SSL=false）
   - 检查SSL证书配置
   ```

3. **认证失败**

   ```
   解决方案：
   - 验证用户名和密码
   - 确认数据库用户权限
   - 检查数据库名称是否正确
   ```

4. **依赖安装失败**
   ```
   解决方案：
   - 使用 --legacy-peer-deps 选项
   - 清除npm缓存：npm cache clean --force
   - 删除node_modules重新安装
   ```

### 调试技巧

1. **查看详细错误信息**

   ```bash
   # 查看应用日志
   pm2 logs vue3-admin

   # 查看数据库连接日志
   tail -f /var/log/postgresql/postgresql-*.log
   ```

2. **手动测试连接**

   ```bash
   # 安装PostgreSQL客户端
   sudo apt-get install postgresql-client

   # 测试连接
   psql -h 数据库主机 -p 5432 -U postgres -d vue3-admin-db
   ```

## 🔐 安全配置

1. **密码安全**
   - 使用强密码
   - 定期更换密码
   - 不要在代码中硬编码密码

2. **网络安全**
   - 启用SSL连接
   - 配置防火墙规则
   - 限制数据库访问IP

3. **权限管理**
   - 使用最小权限原则
   - 为不同用户配置不同权限
   - 定期审查用户权限
