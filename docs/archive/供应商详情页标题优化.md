# 供应商详情页标题优化

## 📝 修改概述

将供应商详情页顶部标题从固定的"**供应商详情**"改为显示**实际的供应商名称**，使页面标题更具有信息价值。

---

## 🔄 修改内容

### 修改前

```vue
<span class="page-title">供应商详情</span>
```

显示效果：

```
[← 返回列表]  供应商详情
```

### 修改后

```vue
<span class="page-title">{{ supplier?.name || '供应商详情' }}</span>
```

显示效果：

```
[← 返回列表]  济都市黎昕印刷集团有限公司
```

---

## 💡 修改说明

### 使用可选链操作符 `?.`

```javascript
supplier?.name;
```

- 如果 `supplier` 为 `null` 或 `undefined`，返回 `undefined`
- 避免运行时错误
- TypeScript 类型安全

### 降级处理 `|| '供应商详情'`

```javascript
supplier?.name || "供应商详情";
```

- 当供应商数据尚未加载时，显示"供应商详情"
- 当供应商名称为空时，显示"供应商详情"
- 确保页面始终有标题显示

## 🎯 优化效果

### 1. **信息价值提升**

- ❌ 修改前：所有供应商详情页都显示"供应商详情"
- ✅ 修改后：直接显示供应商名称，一目了然

### 2. **用户体验改善**

- 用户无需向下滚动查看供应商信息
- 页面顶部就能知道当前查看的是哪个供应商
- 多标签页浏览时更容易识别

### 3. **浏览器标签标题**

虽然此次修改未涉及浏览器标题，但页面标题的改变为后续优化奠定基础。

## 🔍 技术细节

### 数据来源

供应商名称来自 `supplier` ref 对象：

```typescript
// 供应商信息
const supplier = ref<Supplier | null>(null);

// 加载供应商详情
const loadSupplierDetail = async () => {
  try {
    supplierLoading.value = true;
    const res = await getSupplierDetail(supplierId);
    if (res.success) {
      supplier.value = res.data; // 包含 name 属性
    }
  } catch (error) {
    ElMessage.error("加载供应商信息失败");
  } finally {
    supplierLoading.value = false;
  }
};
```

### Supplier 类型定义

```typescript
interface Supplier {
  id: number;
  name: string; // ⭐ 供应商名称
  totalPayable: number;
  // ...其他属性
}
```
