# 供应商欠款金额校验功能说明

## ✅ 功能概述

在供应商详情页添加欠款时，如果上传了Excel产品明细文件，系统会自动校验Excel中所有产品的金额总和是否与填写的欠款金额一致。如果不一致，将无法添加成功并提示错误信息。

## 💡 功能逻辑

### 验证流程

```
1. 用户填写欠款金额（如：¥2000.00）
   ↓
2. 用户上传Excel产品明细文件
   ↓
3. 点击"确定"提交
   ↓
4. 系统解析Excel文件，提取所有产品记录
   ↓
5. 计算Excel中所有产品的金额总和
   ↓
6. 对比欠款金额与Excel总金额
   ↓
7a. 如果一致 → 继续添加欠款
7b. 如果不一致 → 显示错误提示，阻止添加
```

## 📝 核心代码

```typescript
// 提交添加欠款
const handleAddDebtSubmit = async () => {
  if (!addDebtFormRef.value) return;

  await addDebtFormRef.value.validate(async valid => {
    if (valid) {
      try {
        // 如果有Excel文件，先解析Excel
        let excelItems = null;
        if (addDebtForm.excelFile) {
          try {
            excelItems = await parseExcelFile(addDebtForm.excelFile);

            // 验证Excel总金额与填写的欠款金额是否一致
            const excelTotalAmount = excelItems.reduce((sum, item) => sum + item.amount, 0);
            const debtAmount = addDebtForm.amount;

            // 允许0.01的误差（避免浮点数精度问题）
            const tolerance = 0.01;
            if (Math.abs(excelTotalAmount - debtAmount) > tolerance) {
              ElMessage.error(
                `欠款金额(¥${debtAmount.toFixed(2)})与Excel明细总金额(¥${excelTotalAmount.toFixed(2)})不一致，无法添加！`
              );
              return;
            }
          } catch (error) {
            console.error("Excel解析失败:", error);
            ElMessage.error("Excel文件解析失败，请检查文件格式");
            return;
          }
        }

        // ... 继续后续添加逻辑
      }
    }
  });
};
```

## 🔍 验证规则

### 1. **金额对比**

- 欠款金额：用户在表单中填写的金额
- Excel总金额：Excel中所有产品的"金额"列求和

### 2. **误差容忍**

- 允许 **±0.01元** 的误差
- 原因：避免JavaScript浮点数计算精度问题
- 示例：
  - ✅ 欠款: 2000.00，Excel总计: 2000.01 → 允许
  - ✅ 欠款: 2000.00，Excel总计: 1999.99 → 允许
  - ❌ 欠款: 2000.00，Excel总计: 2005.00 → 拒绝

### 3. **校验时机**

- 仅在**上传了Excel文件时**才进行校验
- 如果没有上传Excel，则不进行金额校验

## 📋 使用场景

### 场景1：金额一致（正常情况）

**操作步骤：**

1. 填写欠款金额：¥2000.00
2. 填写描述：原材料采购费用
3. 上传Excel文件，内容如下：

| 产品名称 | 产品型号 | 数量 | 单位 | 单价 | 金额 | 是否含税 |
| -------- | -------- | ---- | ---- | ---- | ---- | -------- |
| 产品A    | M001     | 10   | 个   | 50   | 500  | 是       |
| 产品B    | M002     | 5    | 箱   | 300  | 1500 | 是       |

**Excel总金额**：500 + 1500 = 2000.00

**结果**：✅ 添加成功

---

### 场景2：金额不一致（错误情况）

**操作步骤：**

1. 填写欠款金额：¥2000.00
2. 填写描述：原材料采购费用
3. 上传Excel文件，内容如下：

| 产品名称 | 产品型号 | 数量 | 单位 | 单价 | 金额 | 是否含税 |
| -------- | -------- | ---- | ---- | ---- | ---- | -------- |
| 产品A    | M001     | 10   | 个   | 50   | 500  | 是       |
| 产品B    | M002     | 6    | 箱   | 300  | 1800 | 是       |

**Excel总金额**：500 + 1800 = 2300.00

**结果**：❌ 显示错误提示

```
欠款金额(¥2000.00)与Excel明细总金额(¥2300.00)不一致，无法添加！
```

**解决办法：**

- 方案1：修改欠款金额为 ¥2300.00
- 方案2：修改Excel文件，调整产品金额使总和为 ¥2000.00

---

### 场景3：没有上传Excel（跳过校验）

**操作步骤：**

1. 填写欠款金额：¥2000.00
2. 填写描述：原材料采购费用
3. **不上传Excel文件**

**结果**：✅ 直接添加成功（不进行金额校验）

## 🚨 注意事项

### 1. **浮点数精度问题**

- JavaScript浮点数计算可能存在精度误差
- 示例：0.1 + 0.2 = 0.30000000000000004
- 解决方案：设置容忍度 0.01

### 2. **Excel金额字段**

- 确保Excel中"金额"列存在且为数字类型
- 如果金额列为空或无效，该行数据会被跳过

### 3. **用户体验**

- 错误提示清晰明确，告知具体金额差异
- 允许用户修改后重新提交

### 4. **数据完整性**

- 校验通过后，欠款记录和Excel明细数据的金额保持一致
- 便于后续对账和审计
