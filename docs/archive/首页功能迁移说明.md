## 📊 数据功能

### 统计数据（与原仪表盘相同）

- **客户总数**：系统中所有客户的总数量
- **有欠款客户**：当前有欠款（欠款金额 > 0）的客户数量
- **无欠款客户**：当前无欠款（欠款金额 = 0）的客户数量
- **总计欠款**：所有客户的欠款总额（实时统计）

### 数据来源

- API 接口：`/customer/statistics`
- Mock 数据：基于 50 条测试客户
- 更新方式：页面加载自动获取 + 手动刷新按钮
