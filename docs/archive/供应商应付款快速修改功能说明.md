# 供应商应付款快速修改功能说明

## ✅ 新增功能

在供应商列表中，现在可以**双击总应付款**直接修改应付款金额并保存到数据库！

---

## 🎯 功能特点

### 1. 双击修改

- 在供应商列表的"总应付款"列
- **双击**应付款金额（例如：¥15,000.00）
- 立即弹出修改对话框

### 2. 视觉反馈

- 鼠标悬停时，应付款单元格会：
  - 背景变为浅蓝色
  - 轻微放大效果
  - 鼠标变为手型指针
  - 显示提示文字："双击修改应付款"

### 3. 数据验证

- 应付款金额不能小于 0
- 自动保留两位小数
- 显示当前应付款 vs 新应付款对比

---

## 🚀 使用方法

### 双击修改（新功能）⭐

```
1. 进入供应商列表页面
2. 找到要修改的供应商
3. 双击"总应付款"列的金额
4. 在弹出的对话框中输入新的应付款金额
5. 点击"确定修改"
6. 完成！应付款已更新
```

## 🔧 技术实现

### 1. 添加了新的 API 接口

**API 文件：** `/src/api/supplier.ts`

```typescript
/** 更新供应商信息 */
export const updateSupplier = (data: Supplier) => {
  return http.request<OperationResult>("put", "/supplier/update", { data });
};
```

### 2. 添加了 Mock 接口

**Mock 文件：** `/mock/supplier.ts`

```typescript
// 更新供应商信息
{
  url: "/supplier/update",
  method: "put",
  response: ({ body }) => {
    const index = mockSuppliers.findIndex(item => item.id === body.id);
    if (index !== -1) {
      mockSuppliers[index] = { ...mockSuppliers[index], ...body };
      return { success: true, message: "更新成功" };
    }
    return { success: false, message: "供应商不存在" };
  }
}
```

### 3. 添加了双击事件处理

**列表页面：** `/src/views/supplier/index.vue`

```vue
<span @dblclick="handlePayableDblClick(row)" :title="'双击修改应付款'">
  ¥{{ row.totalPayable.toFixed(2) }}
</span>
```

### 4. 添加了修改对话框

```typescript
// 对话框状态
const editPayableDialogVisible = ref(false);
const currentEditSupplier = ref<Supplier | null>(null);
const editPayableAmount = ref<number>(0);

// 双击处理
const handlePayableDblClick = (row: Supplier) => {
  currentEditSupplier.value = row;
  editPayableAmount.value = row.totalPayable;
  editPayableDialogVisible.value = true;
};

// 提交修改
const handleEditPayableSubmit = async () => {
  const updatedSupplier = {
    ...currentEditSupplier.value!,
    totalPayable: editPayableAmount.value
  };
  await updateSupplier(updatedSupplier);
};
```

## ⚠️ 注意事项

### 1. 数据覆盖

- **双击修改**会直接覆盖原有应付款金额
- 不是在原有基础上增减，而是完全替换
- 修改前会显示当前应付款供参考

### 2. 与欠款明细的关系

- 供应商列表中的"总应付款"是独立字段
- 详情页中的"欠款明细"是另一个管理维度
- 两者可以独立管理，也可以关联使用

### 3. 权限控制

- 当前所有用户都可以修改
- 建议生产环境添加权限验证
- 可以记录修改日志

### 4. 数据验证

- 新应付款金额必须 ≥ 0
- 自动保留两位小数
- 输入非法值会提示错误

### 5. 数据持久化

- Mock 环境中数据保存在内存中
- 页面刷新后恢复到初始状态
- 生产环境会真实保存到数据库

## 📖 API 文档

### updateSupplier

**接口地址：** `PUT /supplier/update`

**请求参数：**

```typescript
{
  id: number; // 供应商ID
  name: string; // 供应商名称
  totalPayable: number; // 新的应付款金额
  createTime: string; // 创建时间
}
```

**返回数据：**

```typescript
{
  success: boolean; // 是否成功
  message: string; // 提示信息
}
```

**调用示例：**

```typescript
const updatedSupplier = {
  id: 1,
  name: "XX材料公司",
  totalPayable: 15500.0,
  createTime: "2024-11-08T10:00:00.000Z"
};

const res = await updateSupplier(updatedSupplier);
// { success: true, message: "更新成功" }
```
