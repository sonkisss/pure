## ⚠️ 常见问题

### Q1: TypeScript类型错误

**问题**：编辑器显示`addTime`类型错误

**原因**：TypeScript编译缓存未更新

**解决方案**：

1. 等待开发服务器自动热更新
2. 或重启开发服务器：
   ```bash
   # 终止当前进程（Ctrl+C）
   pnpm dev
   ```
3. 或清除缓存后重启：
   ```bash
   rm -rf node_modules/.vite
   pnpm dev
   ```

---

### Q2: 添加时间字段不显示

**可能原因**：

1. 浏览器缓存未刷新
2. 代码未正确更新

**解决方案**：

1. 硬刷新浏览器：`Cmd + Shift + R` (Mac) 或 `Ctrl + Shift + R` (Windows)
2. 检查开发服务器是否有热更新提示
3. 检查浏览器控制台是否有错误

---

### Q3: 列表仍显示"创建时间"

**可能原因**：

1. 浏览器缓存
2. 页面未刷新

**解决方案**：

1. 刷新页面
2. 重新进入供应商详情页

---

### Q4: 时间格式不一致

**问题**：显示格式与预期不符

**检查点**：

- `format`属性：`YYYY-MM-DD HH:mm:ss`
- `value-format`属性：`YYYY-MM-DD HH:mm:ss`
- `formatTime`函数：`dayjs(time).format("YYYY-MM-DD HH:mm:ss")`
