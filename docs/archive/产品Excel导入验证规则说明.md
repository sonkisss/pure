## ✅ 已实现的功能

产品Excel导入功能已升级，新增智能验证和去重规则！

---

## 📋 验证规则详解

### 1️⃣ 必填字段验证

所有必填字段必须填写，否则导入失败：

| 字段     | 是否必填 | 验证规则                |
| -------- | :------: | ----------------------- |
| 产品名称 |    ✅    | 不能为空                |
| 规格型号 |    ✅    | 不能为空                |
| 单位     |    ✅    | 不能为空                |
| 进价     |    ✅    | 必须是数字且≥0          |
| 供应商   |    ✅    | 不能为空                |
| 含税类型 |    ✅    | 只能是"普票"或"含税13%" |
| 备注     |    ❌    | 可选                    |

**失败示例：**

```
产品名称: 联想笔记本
规格型号: (空)          ← 失败原因：规格型号不能为空
进价: 3500
```

---

### 2️⃣ 重复数据验证规则

#### 规则 A：与数据库现有数据的重复检查

**检查维度：** 产品名称 + 规格型号 + 供应商

**结果：** 三者完全相同时，**导入失败**

**示例：**

```
数据库现有数据：
- 产品名称: 联想笔记本
- 规格型号: ThinkPad-E580
- 供应商: 联想官方
- 进价: 3500

导入数据：
- 产品名称: 联想笔记本
- 规格型号: ThinkPad-E580
- 供应商: 联想官方         ← 与现有数据完全重复
- 进价: 3600

结果: ❌ 导入失败
失败原因: "产品名称、规格型号、供应商与现有数据重复"
```

#### 规则 B：供应商不同可正常导入

**检查维度：** 产品名称 + 规格型号

**结果：** 名称和型号相同，但**供应商不同**时，可以正常导入

**示例：**

```
数据库现有数据：
- 产品名称: 联想笔记本
- 规格型号: ThinkPad-E580
- 供应商: 联想官方
- 进价: 3500

导入数据：
- 产品名称: 联想笔记本
- 规格型号: ThinkPad-E580
- 供应商: 京东自营         ← 供应商不同
- 进价: 3600

结果: ✅ 导入成功（两条记录并存）
```

---

### 3️⃣ 同一批次导入中的去重规则

#### 规则 C：同名同型号同供应商，保留最低价

**检查维度：** 产品名称 + 规格型号 + 供应商

**处理逻辑：**

1. 如果同一批次导入中有多条记录的 名称+型号+供应商 完全相同
2. 系统会自动比较进价
3. **只保留进价最低的一条记录**
4. 其他记录标记为失败

**示例：**

```
本次导入的Excel中包含：

行2: 联想笔记本, ThinkPad-E580, 联想官方, 3600
行3: 联想笔记本, ThinkPad-E580, 联想官方, 3500  ← 最低价
行4: 联想笔记本, ThinkPad-E580, 联想官方, 3800

结果:
✅ 行3 导入成功 (进价最低: ¥3500)
❌ 行2 导入失败 - 失败原因: "产品名称、规格型号、供应商相同，已保留进价最低(¥3500)的记录"
❌ 行4 导入失败 - 失败原因: "产品名称、规格型号、供应商相同，已保留进价最低(¥3500)的记录"
```

#### 规则 D：同名同型号但供应商不同，各自保留最低价

**示例：**

```
本次导入的Excel中包含：

行2: 联想笔记本, ThinkPad-E580, 联想官方, 3600
行3: 联想笔记本, ThinkPad-E580, 联想官方, 3500  ← 联想官方最低价
行4: 联想笔记本, ThinkPad-E580, 京东自营, 3700
行5: 联想笔记本, ThinkPad-E580, 京东自营, 3550  ← 京东自营最低价

结果:
✅ 行3 导入成功 (联想官方, ¥3500)
✅ 行5 导入成功 (京东自营, ¥3550)
❌ 行2 导入失败 - 已保留联想官方的最低价
❌ 行4 导入失败 - 已保留京东自营的最低价
```

## 🔄 完整的验证流程

```
Excel文件上传
    ↓
第一步：验证必填字段
    ├─ 所有字段格式正确 → 进入第二步
    └─ 有字段缺失/格式错误 → 标记失败
    ↓
第二步：检查与数据库的重复
    ├─ 名称+型号+供应商 不重复 → 进入第三步
    └─ 名称+型号+供应商 重复 → 标记失败
    ↓
第三步：处理本批次内的重复
    ├─ 按 名称+型号 分组
    ├─ 每组内按 供应商 再分组
    └─ 每个供应商组内只保留进价最低的
    ↓
导入完成，返回结果
```

## 💡 使用建议

### 1. 导入前准备

**检查清单：**

- ✅ 确保所有必填字段都已填写
- ✅ 确认进价是纯数字（不要带"元"、"¥"等符号）
- ✅ 确认含税类型只能是"普票"或"含税13%"
- ✅ 检查是否有与现有数据重复的记录

### 2. 利用去重规则优化采购

**场景：** 同一产品有多个供应商报价

**操作：**

1. 将所有供应商报价填入Excel
2. 同一产品的不同报价填在不同行
3. 上传导入
4. 系统自动为每个供应商保留最低报价

**示例Excel：**

```csv
产品名称,规格型号,单位,进价,供应商,含税,备注
iPhone15,128GB,台,5999,苹果官方,含税13%,
iPhone15,128GB,台,5899,京东自营,含税13%,
iPhone15,128GB,台,5799,拼多多,普票,
```

**导入结果：** 三个供应商的记录都会保留（因为供应商不同）

### 3. 处理失败记录

**步骤：**

1. 下载失败明细Excel
2. 查看"失败原因"列
3. 根据失败原因修正数据：
   - 如果是字段缺失 → 补充完整
   - 如果是格式错误 → 修正格式
   - 如果是重复数据 → 决定是否需要导入
4. 重新上传修正后的数据

## ⚠️ 注意事项

### 1. 关于进价比较

- 进价比较是**数值比较**，不是字符串比较
- ¥3500 > ¥3400，会保留¥3400的记录
- 进价为0也是有效值，可以正常导入

### 2. 关于供应商字段

- 供应商是**纯文本字段**，区分大小写
- "联想官方" ≠ "联想官方 " （注意空格）
- "联想官方" ≠ "Lenovo官方"
- 建议统一供应商名称格式

### 3. 关于含税类型

- 只能是"普票"或"含税13%"两个值
- 不支持其他格式，如"13%"、"含税"、"专票"等
- 建议从下拉列表复制粘贴

### 4. 关于Excel格式

- 支持 .xlsx、.xls、.csv 格式
- CSV文件需要UTF-8编码（支持中文）
- 第一行必须是表头
- 数据从第二行开始

## 🔧 技术实现

### Mock层验证逻辑

验证分为4个步骤：

1. **字段验证**：检查必填字段和格式
2. **数据库重复检查**：与现有数据对比
3. **本批次去重**：按名称+型号+供应商分组
4. **价格比较**：每组内保留最低价

### 前端处理

- 导入完成后自动检查失败数量
- 有失败记录时弹出下载提示
- 失败明细包含行号和详细原因
- CSV格式导出，支持Excel打开

## 📞 常见问题

**Q1: 为什么同一产品可以有多条记录？**

A: 只要供应商不同，就可以有多条记录。这是为了支持多供应商比价。

**Q2: 如果我想更新现有产品的价格怎么办？**

A: 有两种方式：

1. 使用"编辑"功能手动修改
2. 先删除旧记录，再导入新数据

**Q3: 导入时系统会自动选择最低价供应商吗？**

A: 不会。系统只会保留每个供应商的最低报价，不会自动选择供应商。

**Q4: 失败明细中的行号是什么？**

A: 是原Excel文件中的行号（从2开始，因为第1行是表头），方便定位错误。

**Q5: 如果Excel中有10000条数据，都会验证吗？**

A: 是的。系统会验证所有数据，但建议分批导入以提高效率。
