## 📝 测试场景

### 测试A：修改金额但未上传Excel（应该失败）❌

**目的**：验证修改金额时必须重新上传Excel的校验

**前提条件**：

- 找到一个已有Excel明细数据的欠款
- 可以通过"Excel明细"列查看，有绿色文档图标 📄 的表示有数据

**操作步骤**：

1. 点击该欠款的"修改"按钮
2. 查看对话框，应该显示：
   ```
   ⚠️ 该欠款已有Excel明细数据，如修改金额请务必重新上传Excel
   ```
3. 修改欠款金额（例如：从 ¥2000 改为 ¥2500）
4. **不上传新的Excel文件**
5. 点击"确定"

**预期结果**：

```
❌ 欠款金额已修改，但该欠款存在Excel明细数据，请重新上传Excel文件以保持数据一致性！
```

**✅ 通过条件**：显示错误提示，修改失败

---

### 测试B：修改金额并上传Excel（金额一致，应该成功）✅

**目的**：验证上传的Excel金额与修改后的欠款金额一致时可以成功

**操作步骤**：

1. 点击该欠款的"修改"按钮
2. 修改欠款金额为：`2005`
3. 点击"下载Excel模板"，准备Excel文件
4. 在Excel中填写数据（确保总金额为 2005）：

| 产品名称   | 产品型号 | 数量 | 单位 | 单价   | 金额 | 是否含税 |
| ---------- | -------- | ---- | ---- | ------ | ---- | -------- |
| 笔记本电脑 | ABC-001  | 10   | 台   | 100.50 | 1005 | 是       |
| 显示器     | DEF-002  | 5    | 台   | 200    | 1000 | 否       |

**Excel总金额**：1005 + 1000 = **2005** ✅

5. 保存Excel文件
6. 在"Excel文件"处点击"选择Excel文件"，上传刚才的文件
7. 点击"确定"

**预期结果**：

```
✅ 欠款修改成功，已更新 2 条产品明细
```

**✅ 通过条件**：

- 修改成功
- Excel明细数据已更新
- 列表刷新后可以点击查看新的Excel明细

---

### 测试C：修改金额并上传Excel（金额不一致，应该失败）❌

```
❌ 修改后的欠款金额(¥3000.00)与新上传Excel明细总金额(¥2000.00)不一致，无法修改！
```

**✅ 通过条件**：显示错误提示，修改失败

## ⚠️ 常见问题排查

### Q1: 修改金额时没有显示警告提示？

**检查**：

- 该欠款是否有Excel数据？
- 查看"Excel明细"列是否有绿色文档图标 📄
- 如果没有，说明该欠款没有Excel数据，不会显示警告

---

### Q2: 上传图片后列表没有刷新？

**解决方案**：

- 手动点击"刷新"按钮
- 或者刷新浏览器页面
- 检查浏览器控制台是否有错误信息

---

### Q3: Excel金额明明一样，却提示不一致？

**检查**：

- Excel中的"金额"列是否包含隐藏的小数位
- 在Excel中设置单元格格式为"数值"，保留2位小数
- 或使用公式：`=ROUND(数量*单价, 2)`

---

### Q4: 图片上传对话框不显示？

**检查**：

- 点击的是否是"图片"列的"上传"按钮
- 检查浏览器控制台是否有错误
- 尝试刷新页面重新操作
