## 💡 核心亮点

### 1. 文件上传功能 ⭐

```vue
<!-- 支持Excel文件上传 -->
<el-upload accept=".xlsx,.xls">
  <el-button>选择Excel文件</el-button>
</el-upload>

<!-- 支持图片上传 -->
<el-upload accept="image/*" list-type="picture-card">
  <el-icon><Plus /></el-icon>
</el-upload>
```

### 2. 数据自动计算

- 总应付款 = 所有未付款欠款的金额之和
- 添加欠款 → 总应付款增加
- 付款 → 总应付款减少
- 修改欠款 → 总应付款重新计算
- 删除未付款欠款 → 总应付款减少

### 3. 状态管理

- 未付款：显示橙色标签，允许付款和修改
- 已付款：显示绿色标签，显示付款时间，只允许删除

### 4. 附件显示

- 📄 绿色文档图标 = Excel文件
- 📷 蓝色图片图标 = 图片文件
- 鼠标悬停显示提示

## 📂 数据结构

### 供应商（Supplier）

```typescript
{
  id: number; // ID
  name: string; // 供应商名称
  totalPayable: number; // 总应付款
  createTime: string; // 创建时间
}
```

### 欠款明细（SupplierDebt）

```typescript
{
  id: number;              // ID
  supplierId: number;      // 供应商ID
  amount: number;          // 欠款金额
  description: string;     // 欠款描述
  excelUrl?: string;       // Excel文件URL（可选）
  imageUrl?: string;       // 图片URL（可选）
  isPaid: boolean;         // 是否已付款
  paidAmount: number;      // 已付金额
  paidTime?: string;       // 付款时间（可选）
  createTime: string;      // 创建时间
  updateTime: string;      // 更新时间
}
```

## ⚠️ 注意事项

### 1. 数据一致性

- 总应付款由系统自动计算，不可手动修改
- 所有欠款操作都会自动更新供应商的总应付款

### 2. 操作限制

- 已付款的欠款不能修改金额和描述
- 已付款的欠款只能删除，不能再次付款
- 删除供应商会同时删除所有欠款明细

### 3. 文件上传

- Mock 环境中文件上传是模拟的
- 文件URL格式：`/uploads/excel/xxx.xlsx` 或 `/uploads/images/xxx.jpg`
- 实际生产环境需要配置真实的文件上传服务
