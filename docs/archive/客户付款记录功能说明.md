### 2️⃣ 客户详情页面

**路由：** `/customer/detail/:id`

**页面内容：**

#### A. 客户基本信息

- 客户ID
- 客户名称
- 当前欠款（欠款金额大于0时显示红色）
- 创建时间

#### B. 统计卡片

- 付款记录总数
- 总欠款金额

#### C. 付款记录列表

- 完整的付款记录表格
- 支持删除操作
- 按创建时间倒序排列

#### D. 汇总信息

- 付款记录总数统计
- 总欠款金额汇总（显著红色数字）

---

### 3️⃣ 新增付款功能

**触发方式：** 在客户详情页点击"新增付款"按钮

**表单字段：**

| 字段     | 类型     | 必填 | 说明                                  |
| -------- | -------- | :--: | ------------------------------------- |
| 付款金额 | 数字     |  ✅  | 必须大于0                             |
| 付款时间 | 日期时间 |  ✅  | 支持选择器，格式：YYYY-MM-DD HH:mm:ss |
| 付款类型 | 下拉选择 |  ✅  | 现金/承兑                             |
| 备注     | 文本域   |  ❌  | 可选，支持多行文本                    |

**验证规则：**

- 付款金额必须大于0
- 付款时间不能为空
- 付款类型必须选择

**业务逻辑：**

1. 添加付款记录成功后
2. 自动减少客户欠款金额
3. 刷新付款记录列表
4. 刷新客户信息

---

## 📊 数据结构

### 付款记录（PaymentRecord）

```typescript
{
  id: number; // 记录ID
  customerId: number; // 客户ID
  amount: number; // 付款金额
  paymentTime: string; // 付款时间
  paymentType: "现金" | "承兑"; // 付款类型
  remark: string; // 备注
  createTime: string; // 创建时间
}
```

## ⚠️ 注意事项

### 1. 付款金额验证

- 付款金额必须大于0
- 添加付款后会自动减少客户欠款
- 如果付款后欠款小于0，系统会自动调整为0

### 2. 删除付款记录

- 删除付款记录后会恢复客户欠款
- 删除操作需要二次确认
- 删除后不可恢复

### 3. 付款时间

- 支持日期时间选择器
- 格式：YYYY-MM-DD HH:mm:ss
- 默认为当前时间

### 4. Mock数据限制

- Mock数据在内存中，刷新页面会重置
- 实际生产环境需要对接真实后端
