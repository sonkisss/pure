# 客户管理模块 - 更新说明

## ✅ 已完成的修改（2024）

### 📋 需求变更

根据您的需求，已对客户管理模块进行了以下简化和功能增强：

---

## 🔄 主要变更

### 1. **简化客户字段**

**原有字段：**

- ❌ 客户名称
- ❌ 联系人
- ❌ 联系电话
- ❌ 邮箱
- ❌ 地址

**新字段（仅2个）：**

- ✅ **客户名称** - 必填
- ✅ **客户欠款** - 必填，数字类型，最小值0

### 2. **新增收款功能** 🆕

添加了完整的收款流程：

- **收款按钮**：每个客户都有独立的收款按钮
- **收款对话框**：输入收款金额
- **实时计算**：自动计算收款后的剩余欠款
- **智能验证**：
  - 收款金额必须大于0
  - 收款金额不能超过当前欠款
  - 无欠款的客户收款按钮自动禁用

### 3. **视觉优化**

- 欠款金额大于0时显示为**红色粗体**
- 欠款为0时显示为普通黑色
- 收款后欠款显示为**绿色粗体**
- 金额统一显示为货币格式（¥XXX.XX）

## 🎯 新增功能详解

### 收款功能流程

1. **点击收款按钮**
   - 打开收款对话框
   - 显示客户名称和当前欠款

2. **输入收款金额**
   - 使用数字输入框，支持小数
   - 自动限制最大值为当前欠款
   - 实时显示收款后的剩余欠款

3. **确认收款**
   - 验证收款金额
   - 更新客户欠款
   - 显示成功提示（包含剩余欠款）
   - 自动刷新列表

4. **收款限制**
   - 收款金额 > 0
   - 收款金额 ≤ 当前欠款
   - 欠款为0的客户收款按钮禁用

## 📝 使用说明

### 添加客户

1. 点击 **"添加客户"** 按钮
2. 输入 **客户名称**（必填）
3. 输入 **客户欠款**（必填，可以为0）
4. 点击 **"确定"** 完成添加

### 收款操作

1. 找到需要收款的客户
2. 点击该客户行的 **"收款"** 按钮
3. 在弹出的对话框中输入 **收款金额**
4. 查看 **收款后欠款** 预览
5. 点击 **"确认收款"** 完成

### 收款示例

**场景：** 张三公司欠款 ¥5,800.50

1. 点击收款按钮
2. 输入收款金额：¥5,000.00
3. 系统显示：收款后欠款 ¥800.50
4. 确认收款
5. 成功提示：收款成功，剩余欠款 ¥800.50
