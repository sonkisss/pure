# 客户欠款快速修改功能说明

## ✅ 新增功能

在客户列表中，现在可以**双击客户欠款**直接修改欠款金额！

---

## 🎯 功能特点

### 1. 双击修改

- 在客户列表的"客户欠款"列
- **双击**欠款金额（例如：¥5,000.00）
- 立即弹出修改对话框

### 2. 视觉反馈

- 鼠标悬停时，欠款单元格会：
  - 背景变为浅蓝色
  - 轻微放大效果
  - 鼠标变为手型指针
  - 显示提示文字："双击修改欠款"

### 3. 数据验证

- 欠款金额不能小于 0
- 自动保留两位小数
- 显示当前欠款 vs 新欠款对比

---

## 🚀 使用方法

### 方法 1：双击修改（新功能）⭐

```
1. 进入客户列表页面
2. 找到要修改的客户
3. 双击"客户欠款"列的金额
4. 在弹出的对话框中输入新的欠款金额
5. 点击"确定修改"
6. 完成！欠款已更新
```

### 方法 2：收款操作（原有功能）

```
1. 进入客户列表页面
2. 点击"收款"按钮
3. 输入收款金额（会从欠款中扣除）
4. 点击"确认收款"
5. 完成！欠款自动减少
```

## 🔧 技术实现

### 1. 添加了新的 API 调用

```typescript
import { updateCustomer } from "@/api/customer";
```

### 2. 添加了双击事件处理

```vue
<span @dblclick="handleDebtDblClick(row)" :title="'双击修改欠款'">
  ¥{{ row.debt.toFixed(2) }}
</span>
```

### 3. 添加了修改对话框

```typescript
// 对话框状态
const editDebtDialogVisible = ref(false);
const currentEditCustomer = ref<Customer | null>(null);
const editDebtAmount = ref<number>(0);

// 双击处理
const handleDebtDblClick = (row: Customer) => {
  currentEditCustomer.value = row;
  editDebtAmount.value = row.debt;
  editDebtDialogVisible.value = true;
};

// 提交修改
const handleEditDebtSubmit = async () => {
  const updatedCustomer = {
    ...currentEditCustomer.value!,
    debt: editDebtAmount.value
  };
  await updateCustomer(updatedCustomer);
};
```

### 4. Mock API 支持

```typescript
// mock/customer.ts 中已有的接口

      return { success: true, message: "更新成功" };
    }
  }
}
```

## ⚠️ 注意事项

### 1. 数据覆盖

- **双击修改**会直接覆盖原有欠款金额
- 不是在原有基础上增减，而是完全替换
- 修改前会显示当前欠款供参考

### 2. 权限控制

- 当前所有用户都可以修改
- 建议生产环境添加权限验证
- 可以记录修改日志

### 3. 数据验证

- 新欠款金额必须 ≥ 0
- 自动保留两位小数
- 输入非法值会提示错误

### 4. 数据持久化

- Mock 环境中数据保存在内存中
- 页面刷新后恢复到初始状态
- 生产环境会真实保存到数据库

## 📖 API 文档

### updateCustomer

**接口地址：** `PUT /customer/update`

**请求参数：**

```typescript
{
  id: number; // 客户ID
  name: string; // 客户名称
  debt: number; // 新的欠款金额
  createTime: string; // 创建时间
}
```

**返回数据：**

```typescript
{
  success: boolean; // 是否成功
  message: string; // 提示信息
}
```

**调用示例：**

```typescript
const updatedCustomer = {
  id: 1,
  name: "张三公司",
  debt: 12500.0,
  createTime: "2024-11-08T10:00:00.000Z"
};

const res = await updateCustomer(updatedCustomer);
// { success: true, message: "更新成功" }
```
