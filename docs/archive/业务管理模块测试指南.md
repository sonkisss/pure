# 业务管理模块 - Chrome DevTools 测试指南

## 测试环境准备

1. 打开 Chrome 浏览器
2. 访问 `http://localhost:8848/`
3. 打开开发者工具（F12 或 Cmd+Option+I）
4. 切换到 **Console** 标签页查看日志
5. 切换到 **Network** 标签页查看网络请求

## 测试步骤

### 1. 测试添加公司

#### 操作步骤：

1. 在浏览器中进入"业务管理" → "选择公司"页面
2. 点击"添加公司"卡片
3. 输入公司名称（例如："测试公司A"）
4. 点击"确定"按钮

#### 在 Chrome DevTools 中验证：

**Console 标签页应该看到：**

```
[添加公司] 准备插入数据: {company_name: "测试公司A", ...}
[添加公司] 成功，插入的ID: X
```

**Network 标签页：**

- 不应该有 HTTP 请求（因为使用的是 Supabase 直接连接）
- 如果看到 Supabase API 请求，可以查看请求详情

#### 验证数据库：

在 Console 中执行以下代码验证数据是否写入：

```javascript
// 在 Console 中执行
const { createClient } =
  await import("https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/+esm");
const supabase = createClient("YOUR_SUPABASE_URL", "YOUR_ANON_KEY");
const { data, error } = await supabase
  .from("companies")
  .select("*")
  .order("created_at", { ascending: false })
  .limit(5);
console.table(data);
```

### 2. 测试编辑公司

#### 操作步骤：

1. 在公司列表中，点击某个公司的"操作"按钮
2. 选择"编辑公司"
3. 修改公司名称（例如：将"测试公司A"改为"测试公司A-已修改"）
4. 点击"确定"按钮

#### 在 Chrome DevTools 中验证：

**Console 标签页应该看到：**

```
[更新公司] ID: X 准备更新数据: {company_name: "测试公司A-已修改", ...}
[更新公司] 成功，更新的行数: 1
```

#### 验证数据库：

在 Console 中执行：

```javascript
const { data, error } = await supabase
  .from("companies")
  .select("*")
  .eq("id", X)
  .single();
console.log("更新后的数据:", data);
```

### 3. 测试删除公司

#### 操作步骤：

1. 在公司列表中，点击某个公司的"操作"按钮
2. 选择"删除公司"
3. 在确认对话框中点击"确定"

#### 在 Chrome DevTools 中验证：

**Console 标签页应该看到：**

```
[删除公司] 准备删除ID: X
[删除公司] 成功，删除的行数: 1
```

**如果公司有关联合同，应该看到：**

```
[删除公司] 失败: 存在关联合同，无法删除
```

#### 验证数据库：

在 Console 中执行：

```javascript
const { data, error } = await supabase
  .from("companies")
  .select("*")
  .eq("id", X)
  .single();
console.log("删除后的查询结果:", data); // 应该返回 null 或空数组
```

## 使用 Supabase MCP 工具验证数据库

### 查看所有公司：

```sql
SELECT * FROM companies ORDER BY created_at DESC;
```

### 查看特定公司：

```sql
SELECT * FROM companies WHERE id = X;
```

### 查看最近的操作：

```sql
SELECT id, company_name, status, created_at, updated_at
FROM companies
ORDER BY updated_at DESC
LIMIT 10;
```

## 常见问题排查

### 问题1：添加公司时没有日志输出

- **检查**：确认 Supabase 客户端已正确初始化
- **检查**：在 Console 中执行 `console.log(window.supabase)` 查看是否有 Supabase 实例

### 问题2：看到错误信息

- **检查 Console 错误**：查看完整的错误堆栈
- **检查 Network 标签**：查看是否有失败的请求
- **检查 RLS 策略**：确认已为表创建了正确的 RLS 策略

### 问题3：数据没有写入数据库

- **检查 RLS 策略**：使用 Supabase MCP 工具检查表的 RLS 策略
- **检查权限**：确认 anon 用户有 INSERT 权限
- **检查 Console 日志**：查看是否有错误信息

## 测试检查清单

- [ ] 添加公司功能正常，数据写入数据库
- [ ] 编辑公司功能正常，数据更新到数据库
- [ ] 删除公司功能正常，数据从数据库删除
- [ ] 删除有关联合同的公司时，提示错误信息
- [ ] Console 中能看到详细的操作日志
- [ ] 所有操作都有成功/失败的反馈消息

## 调试技巧

1. **使用 Console 断点**：在代码中添加 `debugger;` 语句
2. **查看网络请求**：在 Network 标签中筛选 Supabase 相关请求
3. **实时查询数据库**：使用 Supabase MCP 工具执行 SQL 查询
4. **检查响应数据**：在 Console 中查看 API 返回的数据结构
