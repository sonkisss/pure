## 🎬 快速体验

### 体验1：查看产品列表

1. 进入产品管理页面
2. 查看自动生成的30个示例产品
3. 浏览统计卡片数据

### 体验2：添加产品

1. 点击"添加产品"按钮
2. 填写产品信息：
   ```
   产品名称：联想笔记本
   规格型号：ThinkPad-E580
   单位：台
   进价：3500
   供应商：联想官方
   含税类型：含税13%
   备注：办公用笔记本
   ```
3. 点击"确定"保存

### 体验3：Excel批量导入

1. 点击"Excel导入"按钮
2. 点击"下载Excel模板"
3. 打开模板，按格式填写产品数据：
   ```csv
   产品名称,规格型号,单位,进价,供应商,含税,备注
   示例产品1,ABC-001,个,100,示例供应商,普票,测试产品
   示例产品2,ABC-002,箱,200,示例供应商,含税13%,测试产品
   ```
4. 保存并上传文件
5. 点击"开始导入"

### 体验4：搜索产品

1. 在搜索框输入"笔记本"
2. 点击"搜索"按钮
3. 查看搜索结果

### 体验5：编辑和删除

1. 找到任一产品，点击"编辑"
2. 修改产品信息后保存
3. 或点击"删除"按钮删除产品

## 💡 Excel导入详细说明

### 模板格式

下载的模板包含以下列（按顺序）：

```
产品名称 | 规格型号 | 单位 | 进价 | 供应商 | 含税 | 备注
```

### 示例数据

```csv
产品名称,规格型号,单位,进价,供应商,含税,备注
联想笔记本,ThinkPad-E580,台,3500,联想官方,含税13%,办公用
戴尔显示器,U2720Q,台,3000,戴尔官方,普票,27寸4K
罗技鼠标,MX Master 3,个,699,罗技官方,普票,无线鼠标
```

### 重要提示

1. **含税类型**必须是"普票"或"含税13%"，不能是其他值
2. **进价**必须是数字，不能包含"元"、"¥"等文字
3. **必填字段**不能为空（产品名称、规格型号、单位、进价、供应商、含税）
4. 模板为**CSV格式**，可用Excel直接打开编辑
5. 如果某行数据不符合要求，该行会被跳过，不影响其他数据导入

## ⚠️ 注意事项

### 1. Mock环境说明

- 当前使用Mock数据，刷新页面后新增的数据会重置
- 数据仅存在于内存中，不会持久化到数据库
- 生产环境需要对接真实后端API

### 2. 含税类型说明

- **普票**：普通增值税发票
- **含税13%**：税率为13%的增值税专用发票

### 3. 供应商字段说明

- 供应商为**纯文本字段**，不关联供应商管理模块
- 可以手动输入任意供应商名称
- 未来可扩展为下拉选择关联的供应商

## ❓ 常见问题

### Q1: 看不到"产品管理"菜单？

**A:** 请强制刷新浏览器（Ctrl+Shift+R 或 Cmd+Shift+R），路由会自动加载。

### Q2: Excel导入失败？

**A:** 请检查：

1. 文件格式是否为.xlsx、.xls或.csv
2. 含税类型是否为"普票"或"含税13%"
3. 进价是否为纯数字
4. 必填字段是否都已填写

### Q3: 如何对接真实后端？

**A:**

1. 修改 `/src/api/product.ts` 中的API地址
2. 在 `vite.config.ts` 中配置代理
3. 注释或删除 `/mock/product.ts` 的Mock配置

### Q4: 如何修改含税类型选项？

**A:** 编辑 `/src/views/product/index.vue`，修改 `taxTypeOptions` 数组。
