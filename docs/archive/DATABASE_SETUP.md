# 数据库设置说明

## 问题：运费和自定义费用无法保存

如果在使用询价管理功能时遇到"运费保存后刷新页面仍显示0"的问题，是因为数据库中缺少必要的表结构。

## 解决方案

### 方法1：通过Supabase控制台手动创建表（推荐）

1. 登录 [Supabase控制台](https://supabase.com/dashboard)
2. 选择你的项目 `zflehoeaadcganacwksb`
3. 进入 **SQL编辑器**
4. 执行以下SQL脚本创建缺失的表：

```sql
-- 创建利润计算表
CREATE TABLE IF NOT EXISTS profit_calculations (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  inquiry_id BIGINT NOT NULL REFERENCES inquiries(id) ON DELETE CASCADE,
  sale_total DECIMAL(15,2) NOT NULL DEFAULT 0,
  purchase_total DECIMAL(15,2) NOT NULL DEFAULT 0,
  taxable_purchase_total DECIMAL(15,2) NOT NULL DEFAULT 0,
  calculated_tax_fee DECIMAL(15,2) NOT NULL DEFAULT 0,
  freight_fee DECIMAL(15,2) NOT NULL DEFAULT 0,
  estimated_profit DECIMAL(15,2) NOT NULL DEFAULT 0,
  profit_rate DECIMAL(10,2) NOT NULL DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 创建自定义费用表
CREATE TABLE IF NOT EXISTS custom_fees (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  inquiry_id BIGINT NOT NULL REFERENCES inquiries(id) ON DELETE CASCADE,
  label VARCHAR(100) NOT NULL,
  amount DECIMAL(15,2) NOT NULL DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 创建索引以提高查询性能
CREATE INDEX IF NOT EXISTS idx_profit_calculations_inquiry_id ON profit_calculations(inquiry_id);
CREATE INDEX IF NOT EXISTS idx_custom_fees_inquiry_id ON custom_fees(inquiry_id);

-- 创建更新时间戳的触发器函数
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

-- 为profit_calculations表创建更新时间戳触发器
DROP TRIGGER IF EXISTS update_profit_calculations_updated_at ON profit_calculations;
CREATE TRIGGER update_profit_calculations_updated_at
    BEFORE UPDATE ON profit_calculations
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- 为custom_fees表创建更新时间戳触发器
DROP TRIGGER IF EXISTS update_custom_fees_updated_at ON custom_fees;
CREATE TRIGGER update_custom_fees_updated_at
    BEFORE UPDATE ON custom_fees
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- 启用RLS (Row Level Security)
ALTER TABLE profit_calculations ENABLE ROW LEVEL SECURITY;
ALTER TABLE custom_fees ENABLE ROW LEVEL SECURITY;

-- 创建RLS策略 (允许所有操作，根据实际需求调整)
CREATE POLICY "Enable all operations for profit_calculations" ON profit_calculations
    FOR ALL USING (true) WITH CHECK (true);

CREATE POLICY "Enable all operations for custom_fees" ON custom_fees
    FOR ALL USING (true) WITH CHECK (true);
```

5. 点击 **运行** 按钮执行SQL脚本

## 验证设置

执行完SQL脚本后，你可以通过以下方式验证：

1. 在Supabase控制台的 **表编辑器** 中查看是否出现了两个新表：
   - `profit_calculations`
   - `custom_fees`

2. 重新登录应用，进入询价详情页面，尝试添加运费，然后刷新页面验证是否正确保存。

## 功能说明

创建表后，以下功能将正常工作：

- ✅ 运费保存和持久化
- ✅ 自定义费用管理
- ✅ 利润计算数据存储
- ✅ 询价单统计功能
- ✅ 费用明细跟踪

## 技术细节

- `profit_calculations` 表存储每个询价单的利润计算数据，包括运费
- `custom_fees` 表存储用户定义的额外费用项
- 两个表都与 `inquiries` 表建立了外键关系
- 启用了行级安全策略以确保数据安全
