# 供应商欠款添加功能调试指南

## 🐛 问题描述

输入欠款金额和欠款描述后，提交成功，但列表中显示的金额和描述为空。

## 🔍 已实施的修复

### 1. Vue响应性修复

✅ 将表单对象从`ref({})`改为`reactive({})`
✅ 移除所有`.value`访问
✅ 使用`Object.assign()`重置表单

### 2. Mock数据处理优化

✅ 简化FormData解析逻辑
✅ 添加详细的调试日志
✅ 移除废弃的`isPaid`等字段

### 3. 前端调试日志

✅ 添加表单数据打印
✅ 添加FormData内容打印
✅ 添加API响应打印

## 🔎 问题诊断

### 情况1：前端表单数据为0或空

**日志显示：**

```javascript
提交前的表单数据: Proxy { amount: 0, description: "" }
```

**原因：**

- ❌ 表单响应性问题
- ❌ 双向绑定失效

**解决方案：**

```
确认是否使用了 reactive() 而不是 ref()
检查 v-model 绑定是否正确
```

### 情况2：FormData中的数据为空

**日志显示：**

```javascript
FormData内容:
amount = 0
description =
```

**原因：**

- ❌ 表单数据没有正确传递到FormData
- ❌ reactive对象访问方式错误

**解决方案：**

```typescript
// ❌ 错误
formData.append("amount", String(addDebtForm.value.amount));

// ✅ 正确
formData.append("amount", String(addDebtForm.amount));
```

### 情况3：Mock层接收的body为空或undefined

**日志显示：**

```javascript
Mock接收到的body: undefined;
或;
Mock接收到的body: {
}
```

**原因：**

- ❌ axios请求未正确发送数据
- ❌ vite-plugin-fake-server配置问题

**解决方案：**

```
1. 检查 src/api/supplier.ts 中的请求配置
2. 确认 Content-Type 为 multipart/form-data
3. 重启开发服务器
```

### 情况4：Mock解析后的数据为0

**日志显示：**

```javascript
解析后的数据: { amount: 0, description: "", ... }
```

**原因：**

- ❌ body数据格式不符合预期
- ❌ 类型转换失败

**解决方案：**

```
检查body的实际结构
可能需要调整Mock解析逻辑
```

### 情况5：API响应正确但列表未更新

**日志显示：**

```javascript
API响应: { success: true, data: { amount: 5000, ... } }
```

**原因：**

- ❌ handleRefresh() 未正确调用
- ❌ 列表数据未重新加载

**解决方案：**

```typescript
// 确认刷新逻辑
const handleRefresh = () => {
  loadSupplierDetail();
  loadDebts(); // ✅ 必须调用
  loadPayments();
};
```
