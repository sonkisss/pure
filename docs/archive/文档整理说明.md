## 📝 新的开发流程

### 开发新功能时

1. **开发前**:

   ```bash
   # 查看最新开发记录
   pnpm changelog
   ```

2. **开发中**:
   - 按照代码规范编写代码
   - 提交代码遵守Git规范

3. **开发后**:
   - 打开 `CHANGELOG.md`
   - 在顶部添加新的记录
   - 格式参考文档中的模板

4. **检查**:
   ```bash
   # 检查是否违反文档规则
   pnpm docs:check
   ```

### 记录格式模板

```markdown
## YYYY-MM-DD

### ✨ 新功能 / 🐛 Bug修复 / 🎨 UI优化

#### ✅ 功能标题

**功能描述**: 简要描述

**实现细节**:

- 详细说明1
- 详细说明2

**相关文件**:

- `src/path/to/file.vue`

**测试状态**: ✅ 已测试

---
```
