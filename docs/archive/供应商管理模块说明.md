## 📁 创建的文件

### 1. API 接口层

**文件：** `/src/api/supplier.ts`

定义了所有供应商和欠款明细相关的接口：

**供应商接口：**

- `getSupplierList()` - 获取供应商列表
- `addSupplier()` - 添加供应商
- `deleteSupplier()` - 删除供应商
- `batchDeleteSupplier()` - 批量删除供应商
- `getSupplierDetail()` - 获取供应商详情
- `getSupplierStatistics()` - 获取统计信息

**欠款明细接口：**

- `getSupplierDebts()` - 获取欠款明细列表
- `addSupplierDebt()` - 添加欠款（支持文件上传）
- `updateSupplierDebt()` - 修改欠款
- `paySupplierDebt()` - 付款操作
- `deleteSupplierDebt()` - 删除欠款

### 2. Mock 数据层

**文件：** `/mock/supplier.ts`

提供完整的 Mock 数据服务：

- 自动生成 30 个供应商
- 每个供应商生成 1-5 笔欠款明细
- 支持所有 CRUD 操作
- 智能计算总应付款

### 3. 路由配置

**文件：** `/src/router/modules/supplier.ts`

配置了两个路由：

- `/supplier/index` - 供应商列表页
- `/supplier/detail/:id` - 供应商详情页

### 4. 供应商列表页面

**文件：** `/src/views/supplier/index.vue`

### 5. 供应商详情页面

## 💡 核心功能详解

### 1. 添加供应商

**步骤：**

1. 点击"添加供应商"按钮
2. 输入供应商名称（必填）
3. 输入初始应付款（必填，可以为0）
4. 点击确定

**字段验证：**

- 供应商名称：不能为空
- 应付款金额：不能小于0

---

### 2. 添加欠款（支持文件上传）⭐

这是最复杂的功能！

**步骤：**

1. 在供应商列表点击"详情"进入详情页
2. 点击"添加欠款"按钮
3. 填写欠款信息：
   - 欠款金额（必填）
   - 欠款描述（必填）
   - 上传 Excel 文件（可选）
   - 上传图片（可选）
4. 点击确定

**文件上传：**

```vue
<!-- Excel 上传 -->
<el-upload
  :auto-upload="false"
  :on-change="handleExcelChange"
  accept=".xlsx,.xls"
>
  <el-button>选择Excel文件</el-button>
</el-upload>

<!-- 图片上传 -->
<el-upload
  :auto-upload="false"
  :on-change="handleImageChange"
  accept="image/*"
  list-type="picture-card"
>
  <el-icon><Plus /></el-icon>
</el-upload>
```

**文件处理：**

```typescript
const formData = new FormData();
formData.append("amount", "5000");
formData.append("description", "原材料费");
formData.append("excelFile", excelFile);
formData.append("imageFile", imageFile);

await addSupplierDebt(supplierId, formData);
```

**效果：**

- 添加成功后，供应商的总应付款会自动增加
- 欠款明细列表会显示新记录
- 附件列会显示文件图标

---

### 3. 修改欠款

**限制：** 只能修改未付款的欠款

**步骤：**

1. 在欠款明细列表找到未付款的欠款
2. 点击"修改"按钮
3. 修改金额或描述
4. 点击确定

**自动更新：**

- 修改金额后，供应商总应付款会自动重新计算

---

### 4. 付款操作

**步骤：**

1. 在欠款明细列表找到未付款的欠款
2. 点击"付款"按钮
3. 输入付款金额（默认为欠款全额）
4. 点击确定

**验证规则：**

- 付款金额必须大于 0
- 付款金额不能大于欠款金额

**付款后的变化：**

```
状态: 未付款 → 已付款
付款信息显示:
  - 已付金额：¥5,000.00
  - 付款时间：2024-11-08 14:30
操作按钮:
  - "付款"和"修改"按钮消失
  - 只保留"删除"按钮
供应商总应付款:
  - 自动减少付款金额
```

---

### 5. 数据一致性保证

**自动计算总应付款：**

```javascript
// 总应付款 = 所有未付款欠款的金额之和
totalPayable = sum(未付款欠款.amount);
```

**操作影响：**
| 操作 | 对总应付款的影响 |
|------|-----------------|
| 添加欠款 | +欠款金额 |
| 修改欠款 | 重新计算 |
| 付款 | -付款金额 |
| 删除未付款欠款 | -欠款金额 |
| 删除已付款欠款 | 无影响 |

## 🎯 使用场景

### 场景 1：新增供应商

```
1. 签约新供应商"XX材料公司"
2. 点击"添加供应商"
3. 输入名称：XX材料公司
4. 初始应付款：0（暂无欠款）
5. 提交
```

### 场景 2：记录采购欠款

```
1. 从供应商采购了一批原材料，价值 ¥10,000
2. 进入供应商详情页
3. 点击"添加欠款"
4. 填写：
   - 金额：10000
   - 描述：原材料采购费用
   - 上传采购订单 Excel
   - 上传收货凭证图片
5. 提交
6. 供应商总应付款变为 ¥10,000
```

### 场景 3：部分付款

```
1. 支付了 ¥6,000
2. 在欠款明细中点击"付款"
3. 输入付款金额：6000
4. 确认
5. 结果：
   - 该欠款标记为"已付款"
   - 显示付款金额 ¥6,000
   - 供应商总应付款减少 ¥6,000
```

### 场景 4：修改欠款信息

```
1. 发现之前记录的金额有误
2. 点击"修改"按钮
3. 更正金额：10000 → 9500
4. 提交
5. 供应商总应付款自动重新计算
```

## ⚠️ 注意事项

### 1. 数据一致性

- 总应付款由系统自动计算，不可手动修改
- 添加/修改/删除欠款后会自动更新总应付款
- 付款操作会立即更新供应商总应付款

### 2. 操作限制

- **已付款的欠款不能修改**
- 已付款的欠款只能删除，不能再次付款
- 删除供应商会同时删除所有欠款明细

### 3. 文件上传

- Mock 环境中文件上传是模拟的
- 实际生产环境需要配置真实的文件上传服务
- 建议使用对象存储服务（如 OSS）

### 4. 权限控制

当前未实现权限控制，建议添加：

- 谁可以添加欠款？
- 谁可以付款？
- 谁可以删除记录？
