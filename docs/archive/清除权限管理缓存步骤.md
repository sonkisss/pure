## 💡 为什么需要清除缓存？

### 1. Vue Router 缓存

Vue Router 会将路由信息缓存在内存中，需要刷新才能重新加载。

### 2. 浏览器缓存

浏览器会缓存 JavaScript 文件，旧的路由配置可能还在缓存中。

### 3. LocalStorage 缓存

系统可能将菜单信息存储在 LocalStorage 中，需要清除。
