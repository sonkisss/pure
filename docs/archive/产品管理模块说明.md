## 📁 创建的文件

### 1. API 接口层

**文件：** `/src/api/product.ts`

定义了所有产品相关的接口：

**产品接口：**

- `getProductList()` - 获取产品列表（支持分页和模糊搜索）

- `updateProduct()` - 更新产品信息
- `deleteProduct()` - 删除单个产品
- `batchDeleteProduct()` - 批量删除产品
- `batchAddProducts()` - 批量添加产品（Excel导入）
- `getProductStatistics()` - 获取统计信息

### 3. 路由配置

**文件：** `/src/router/modules/product.ts`

配置了产品路由：

## 💡 核心功能详解

### 1. 添加产品

**步骤：**

1. 点击"添加产品"按钮
2. 填写产品信息：
   - 产品名称（必填）
   - 规格型号（必填）
   - 单位（必填）
   - 进价（必填，≥0）
   - 供应商（必填）
   - 含税类型（必填，下拉选择：普票/含税13%）
   - 备注（可选）
3. 点击确定

**字段验证：**

- 产品名称、规格型号、单位、供应商：不能为空
- 进价：必须≥0
- 含税类型：必须选择

---

### 2. 编辑产品

**步骤：**

1. 在产品列表中点击"编辑"按钮
2. 修改产品信息
3. 点击确定保存

**注意：**

- 所有字段均可修改
- 修改后立即生效

---

### 3. 删除产品

**单个删除：**

1. 点击产品行的"删除"按钮
2. 确认删除操作

**批量删除：**

1. 勾选要删除的产品（可多选）
2. 点击"批量删除"按钮
3. 确认删除操作

---

### 4. 模糊搜索

**支持的搜索字段：**

- 产品名称
- 规格型号
- 供应商名称

**使用方法：**

1. 在搜索框输入关键词
2. 点击"搜索"按钮或按回车键
3. 点击"重置"清空搜索条件

---

### 5. Excel批量导入 ⭐

这是核心功能！

**步骤：**

1. 点击"Excel导入"按钮
2. 点击"下载Excel模板"按钮获取模板
3. 按照模板格式填写产品数据
4. 上传填好的Excel文件
5. 点击"开始导入"

**Excel模板字段：**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 产品名称 | 文本 | 是 | 产品的名称 |
| 规格型号 | 文本 | 是 | 产品的规格型号 |
| 单位 | 文本 | 是 | 如：个、箱、台等 |
| 进价 | 数字 | 是 | 必须≥0 |
| 供应商 | 文本 | 是 | 供应商名称 |
| 含税 | 文本 | 是 | 仅支持"普票"或"含税13%" |
| 备注 | 文本 | 否 | 备注信息 |

**导入说明：**

- 模板为CSV格式（兼容Excel）
- 含税类型仅支持"普票"或"含税13%"两个值
- 进价必须为数字，不能小于0
- 所有必填字段必须填写，否则该行数据会被跳过
- 导入成功后会显示成功导入的数量

**示例数据：**

```csv
产品名称,规格型号,单位,进价,供应商,含税,备注
示例产品,ABC-001,个,100,示例供应商,普票,这是一个示例
```

## 📂 文件上传说明

### 支持的文件类型

| 类型  | 格式        | 说明                 |
| ----- | ----------- | -------------------- |
| Excel | .xlsx, .xls | Excel 2007及以上版本 |
| CSV   | .csv        | 逗号分隔值文件       |

### 上传限制

- **每次限制 1 个文件**
- **文件大小**：建议 < 10MB
- **上传方式**：使用 FormData

### 模板下载

- 模板为CSV格式（UTF-8编码）
- 包含BOM头，支持中文显示
- 可直接用Excel打开编辑

---

## ⚠️ 注意事项

### 1. 数据验证

- 进价必须为数字，不能小于0
- 含税类型只能是"普票"或"含税13%"
- 所有必填字段不能为空

### 2. 操作限制

- 删除产品操作不可恢复，请谨慎操作
- 批量导入时，数据格式错误的行会被跳过

### 3. Excel导入

- Mock 环境中文件上传是模拟的
- 模板使用CSV格式，兼容Excel
- 实际生产环境需要配置真实的文件解析服务

### 4. 供应商字段

- 供应商为纯文本字段，不关联供应商表
- 可以手动输入任意供应商名称
