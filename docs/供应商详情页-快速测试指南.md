## ✅ 5分钟快速测试

### 测试1: 添加欠款（含图片）⏱️ 1分钟

```
1. 点击"添加欠款"按钮
2. 输入金额: 5000
3. 输入描述: 测试欠款
4. 点击图片上传区域，选择一张图片 📷
5. 点击"确定"

✓ 检查点:
  - 提示"欠款添加成功，图片凭证已上传"
  - 欠款列表出现新记录
  - 图片列显示蓝色图标 🔵
  - 未付款金额增加5000元 📈
```

### 测试2: 修改欠款（更新图片）⏱️ 1分钟

```
1. 找到刚添加的欠款，点击"修改"
2. 修改金额: 5000 → 6000
3. 上传新的图片（或删除图片重新上传）📷
4. 点击"确定"

✓ 检查点:
  - 提示"修改成功"
  - 金额更新为6000
  - 点击图片图标可预览新图片
  - 未付款金额增加1000（变为原值+1000）📈
```

### 测试3: 新增付款 ⏱️ 1分钟

```
1. 滚动到"付款记录"区域
2. 点击"新增付款"
3. 输入金额: 3000
4. 选择日期: 今天
5. 选择类型: 现金
6. （可选）上传凭证图片
7. 点击"确定新增"

✓ 检查点:
  - 提示付款成功
  - 付款列表出现新记录
  - 未付款金额减少3000 📉
  - 已付款金额增加3000 📈
```

### 测试4: 图片预览 ⏱️ 30秒

```
1. 在欠款列表找到有图片的记录
2. 点击蓝色图标 🔵

✓ 检查点:
  - 弹出图片预览对话框
  - 图片清晰显示
  - 可以点击关闭
```

### 测试5: 添加欠款（含Excel）⏱️ 1.5分钟

```
1. 点击"添加欠款"
2. 输入金额: 10000
3. 输入描述: Excel测试
4. 点击"下载Excel模板" 📥
5. 打开模板，填写几行数据
6. 上传刚填写的Excel文件 📄
7. 点击"确定"

✓ 检查点:
  - 提示"已导入 X 条产品明细"
  - Excel列显示绿色图标 + 条数 📄
  - 点击图标可跳转到产品明细页
```

## 🐛 常见问题

### Q: 图片上传后没有显示？

**A**:

1. 检查文件格式是否为图片（jpg、png等）
2. 刷新页面重试
3. 查看浏览器控制台是否有错误

### Q: 未付款金额没有更新？

**A**:

1. 等待1-2秒，数据正在刷新
2. 手动点击"刷新"按钮
3. 检查是否有网络请求失败

### Q: Excel上传失败？

**A**:

1. 确保文件格式为.xlsx或.xls
2. 检查Excel是否包含必填字段
3. 下载模板参考正确格式
